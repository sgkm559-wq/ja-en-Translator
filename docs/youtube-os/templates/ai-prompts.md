# AIプロンプト集（制作ワークフロー用）

[`13-ai-production-workflow.md`](../13-ai-production-workflow.md) の各工程で使うプロンプトです。Claude、ChatGPT、Gemini などの汎用AIアシスタントで使えます。
`{ }` の部分を自分の情報に置き換えてください。

## 共通の前提（毎回、最初に貼る）

```
あなたは日本語のYouTubeチャンネル「{チャンネル名}」の制作アシスタントです。

チャンネルの約束：AI翻訳を使って英語を書く社会人が、失礼にならず、ちゃんと伝わる英語に仕上げられるようになる。
運営者：日英翻訳アプリを自作した開発者。
視聴者：英語を仕事で使う日本人の会社員（25〜45歳、TOEIC 500〜750程度）。DeepLやChatGPTで英文を作ってそのまま送っているが、失礼でないか不安。
トーン：論理的、親切、AIの誤訳にはちょっと辛口。AIを否定せず使いこなし方を教える。

ルール：
- 事実や英文に自信がない場合は、推測で書かずに「要確認」と明記してください。
- AIツールの出力を想像で書かないでください。必要な箇所は【実際の出力を入れる】と書いてください。
```

## リサーチ・企画

### R1：視聴者の悩みを整理する
```
以下は、競合動画のコメントと、YouTube検索のサジェストです。
視聴者の「悩み」「質問」「不満」を分類し、似たものをまとめて、多い順に10個並べてください。
それぞれに、代表的なコメントを1つ引用し、動画企画のヒントを1行で書いてください。

【コメント】
{コメントを貼り付け}

【検索サジェスト】
{サジェストを貼り付け}
```

### R2：企画を採点する
```
以下の企画候補を、次の3つの基準で1〜5点で採点し、合計点の高い順に並べてください。
- 需要：視聴者が実際に検索したり、悩んだりしているか
- 差別化：翻訳アプリ開発者という立場や、AI翻訳の検証という切り口が活きるか
- 制作しやすさ：週6時間の制作時間で、検証・台本・編集ができるか

それぞれの点数の理由を1行で書き、最後に「今週作るべき1本」と、その理由を書いてください。

【企画候補】
{企画を箇条書き}
```

### R3：企画の角度を広げる
```
テーマ「{テーマ}」について、次の5つの角度で動画企画を1つずつ出してください。
1. 失敗（〇〇は実は間違い）
2. ランキング（〇〇を△△順に並べる）
3. 対決（AとBどっちが上？）
4. 実験（〇〇してみた結果）
5. 謎解き（なぜ〇〇なのか）

それぞれに、10秒で説明できる1文のコンセプトと、視聴者がクリックしたくなる理由を書いてください。
```

## パッケージ

### P1：タイトル案を出す
```
次の動画のタイトル案を20個出してください。

動画の内容：{1文で}
動画で必ず回収できる約束：{視聴者が得られるもの}
検索されている言葉：{例：了解しました 英語}

条件：
- 警告、ランキング、対決、実験、謎解き、権威の6つの型からそれぞれ3個以上
- 32文字以内、前半15文字で意味が通じる
- 動画で回収できない誇張はしない
最後に、おすすめの3つを選び、理由を書いてください。
```

### P2：サムネイルの構図案を出す
```
タイトル「{タイトル}」の動画のサムネイル構図を5案出してください。

チャンネルの共通ルール：白背景、誤り＝赤×、正解＝緑○、文字は8文字以内、主役は1つ。
使える型：比較×○、ロゴ全滅、採点表、驚き顔＋1行、ランキング。

各案について、画面の配置（左・中央・右）、入れる文字、色、視聴者が「答えを知りたい」と思う問いは何か、を書いてください。
サムネの文字はタイトルと同じ言葉を繰り返さないでください。
```

## 台本

### S1：構成案を作る
```
以下の企画ブリーフから、{8〜10}分の動画の構成案を作ってください。

構成の型：{検証 / ランキング / 謎解き / ビフォーアフター}
ルール：
- 0〜30秒：視覚フック → 言葉のフック → 約束 → 語れる理由 → 最後まで見る理由（オープンループ）
- 本編の各項目は「問題 → 答え → 理由 → 例文」
- 項目は価値の低い順から高い順に並べる
- 60〜90秒ごとに、次の内容を予告する一言（リフック）を入れる
- 中盤（全体の30〜60%）に5秒以内の登録の呼びかけ
- 最後は締めの挨拶をせず、次の動画「{次の動画}」へつなぐ
各パートに秒数の目安を付けてください。

【企画ブリーフ】
{ブリーフを貼り付け}
```

### S2：台本の初稿を書く
```
以下の構成案から、台本の初稿を書いてください。

形式：
- 「話す」（ナレーション）と「画面」（テロップ・映像・効果音）を分けて書く
- 話し言葉、1文40文字以内
- 英文は必ず「画面」にも表示する
- 1分あたり約300文字
- 私が自分の経験や検証結果を書き足すべき箇所には【自分の経験を入れる】、AIツールの出力が入る箇所には【実際の出力を入れる】と書く
- 英文の自然さに自信がないものは【要確認】と書く

【構成案】
{構成案を貼り付け}
```

### S3：台本を批評する（維持率チェック）
```
あなたは厳しいYouTube編集者です。以下の台本を、視聴者が離脱しそうな箇所という観点で批評してください。

確認すること：
1. 最初の5秒でタイトル「{タイトル}」の約束が回収されているか
2. 前置き・挨拶・脱線など、削れる部分はどこか
3. 60秒以上、新しい驚きや予告がない区間はどこか
4. オープンループは開かれ、回収されているか
5. 説明が長すぎる・分かりにくい箇所はどこか
6. 英文や事実で、確認が必要な箇所はどこか

それぞれ、該当箇所を引用し、具体的な修正案を書いてください。最後に、全体の20%を削るなら、どこを削るべきかを提案してください。

【台本】
{台本を貼り付け}
```

## 公開

### U1：説明文・チャプター・固定コメント
```
以下の台本と、編集後の各パートの開始時間から、YouTubeの公開用テキストを作ってください。

1. 説明文
   - 最初の2行：検索語「{検索語}」を自然に含め、動画で得られることを書く
   - その後：リンクの置き場所（［早見表］［アプリ］）、チャプター、注意書き（AIの出力の取得日）
2. チャプター：00:00から始め、各チャプター名は15文字以内で内容が分かるように
3. 固定コメント：視聴者が答えたくなる問いかけを1つ（例：あなたならどう訳す？）

【台本】
{台本}

【各パートの開始時間】
{例：00:00 オープニング / 02:30 なぜ全滅？ ...}
```

## Shorts・他プラットフォーム

### SH1：切り抜き候補を探す
```
以下の文字起こし（タイムスタンプ付き）から、縦型ショート動画にできる部分を5つ選んでください。

条件：
- 20〜45秒で、それだけで意味が完結する
- 最初の2秒で問いが立つ、または冒頭に問いのテロップを足せば成立する
- 驚きのある結果、すぐ使える答え、ビフォーアフターのいずれかを含む

それぞれについて、開始・終了時間、冒頭に足すテロップ（15文字以内）、最後を冒頭の問いにつなげる一言、を書いてください。

【文字起こし】
{文字起こしを貼り付け}
```

### RP1：プラットフォーム別に文章を書き分ける
```
以下の動画の要点から、各プラットフォーム用の投稿文を作ってください。

1. YouTube Shorts のタイトル（30文字以内）
2. TikTok のキャプション（検索されやすい言葉を含め、100文字程度）
3. Instagram Reels のキャプション（要点3つ＋保存を促す一言＋ハッシュタグ5個）
4. X / Threads の投稿（140文字以内、Before/After 画像に添える文）
5. LinkedIn の投稿（ビジネス向けのトーンで300文字程度）
6. note / ブログ記事の見出し構成（H2を5つ）

どれも、元の長尺動画への導線を入れてください。誇張はしないでください。

【動画の要点】
{要点を貼り付け}
```

## アナリティクス

### A1：週次レビュー
```
以下は、私のYouTubeチャンネルの直近の動画の指標です（CSV）。
最新の動画を、その前の4本と比べて分析してください。

1. 最新の動画で、前の4本より良かった指標・悪かった指標
2. CTRと平均再生率の組み合わせから見た状態（両方高い / CTRだけ高い / 維持率だけ高い / 両方低い）
3. 考えられる理由（企画・サムネ・タイトル・冒頭・構成のどれか）
4. 来週試すべき実験の候補を3つ（変える変数は1つずつ、成功基準付き）

数字から言えないことは推測だと明記してください。

【データ】
{kpi-tracker.csv の内容を貼り付け}
```
