# 12. アルゴリズム理解にもとづく成長戦略

> **このファイルの根拠**：YouTube が公式に説明している推薦の仕組み（Creator Insider、YouTube 公式ヘルプ、YouTube Liaison の発信）と、YouTube Studio で確認できる指標の定義をもとにしています。
> アルゴリズムの内部は公開されていないため、「公式に説明されていること」と「実務上の経験則」を分けて書いています。仕様は変わるため、迷った時は YouTube Studio の表示と公式ヘルプを優先してください。

---

## 1. まず押さえる大原則

### アルゴリズムは「動画」ではなく「視聴者」を見ている
YouTube の推薦システムは、**一人ひとりの視聴者が、この動画を見て満足するか** を予測して、どの動画を見せるか決めています。
「チャンネルを評価して順位をつける」仕組みではありません。YouTube 自身も「アルゴリズムは視聴者の行動に従う」と説明しています。

つまり、成長戦略は次の1文に集約されます。

> **特定の視聴者が「クリックしたい」と思い、見た後に「見てよかった」と思う動画を、繰り返し出す。**

### 推薦システムが見ている主なシグナル（公式に説明されているもの）
| シグナル | 何を表すか | 関係する Studio の指標 |
|---------|-----------|---------------------|
| クリックしたか | 動画が「見たい」と思われたか | インプレッションのクリック率（CTR） |
| どれだけ見たか | 期待に応えたか | 平均視聴時間、平均再生率、維持率グラフ |
| 満足したか | 見てよかったか | 高評価・低評価、「興味なし」、視聴後アンケート（Studio では見えない） |
| その後どうしたか | 次も見たか、YouTube を続けて使ったか | 終了画面のクリック、セッション（直接は見えない） |
| 繰り返し見に来るか | チャンネルへの愛着 | リピーター、登録者からの視聴 |

**重要：どれか1つの指標だけでは決まりません。** CTR が高くても途中で離脱されれば広がらず、維持率が高くてもクリックされなければ見つけてもらえません。

## 2. 6つの流入経路と、それぞれの攻略法

YouTube Studio の「アナリティクス → コンテンツ → トラフィックソース」で、各動画がどこから見られているかを確認できます。

### ① ブラウジング機能（ホーム画面・登録チャンネルフィード）
- **仕組み**：視聴者が何も検索せずに YouTube を開いた時に表示される。その人の過去の視聴履歴と、似た視聴者が満足した動画から選ばれる。
- **効く要素**：CTR（クリックしたくなるか）× 満足度（見続けたか）。新規チャンネルでも、最初に既存の視聴者・登録者で反応が良いと、似た視聴者へ徐々に広がる。
- **攻略法**：
  - 検索されない言葉でもクリックしたくなる「好奇心ベース」の企画（例：「お疲れ様です」をAI5社に訳させたら全滅）
  - サムネとタイトルで「問い」を作る（[`10-production-system.md`](10-production-system.md) 4・5章）
  - 登録者が反応する企画を続け、最初の反応を強くする

### ② 関連動画（再生中の動画の横・下・終了後）
- **仕組み**：今見ている動画と一緒に見られることが多い動画、話題が近い動画が表示される。
- **効く要素**：テーマの近さ、一緒に視聴された実績、その動画の満足度。
- **攻略法**：
  - **競合の人気動画と同じテーマを、別の角度で作る**（同じ視聴者が次に見たくなる動画になる）
  - 自分の動画同士をつなぐ：シリーズ、再生リスト、終了画面、台本の最後で次の動画を紹介
  - タイトル・説明文に、関連する人気動画と同じ主要語を自然に含める

### ③ YouTube 検索
- **仕組み**：検索語との関連性（タイトル・説明文・字幕などの内容）、エンゲージメント（その検索語でクリックされ満足されたか）、視聴者個人の履歴で順位が決まる。
- **効く要素**：検索語との一致、検索結果での CTR、視聴後の満足度。
- **攻略法**：
  - YouTube の検索サジェストに出る言葉をタイトルの前半に入れる（例：「了解しました 英語」）
  - 説明文の最初の2行に、検索語と動画の価値を書く
  - チャプター（タイムスタンプ）を付ける：検索結果に表示され、特定の答えを探す人を呼び込む
  - 字幕を正確に直す：内容の理解に使われる可能性があり、無音視聴者の維持にも効く
  - **新規チャンネルの最初の土台**：ホーム画面の推薦はデータが必要だが、検索は最初から見つけてもらえる

### ④ Shorts フィード
- **仕組み**：スワイプで次々に表示。長尺とはほぼ別の仕組みで評価される。
- **効く要素**：「スワイプされずに見られた割合（視聴率）」、平均再生率、ループ再生、エンゲージメント。
- **攻略法**：
  - 1フレーム目から本題（[`04-retention-framework.md`](04-retention-framework.md) 3章）
  - 最後を最初につなげてループさせる
  - **関連動画リンク**で長尺へ誘導する
- **注意**：Shorts の視聴者が長尺の登録者になるとは限らない。Shorts は「チャンネルの存在を知ってもらう」入口として使い、登録者増と長尺の視聴につながっているかを毎月確認する。

### ⑤ チャンネルページ・再生リスト
- 動画を気に入った人がチャンネルページを訪れた時に、**次に見るもの**が分かりやすく並んでいるかが、登録とリピートに直結する。
- 攻略法は「6章：視聴者を登録者に変える方法」を参照。

### ⑥ 外部（X、ブログ、アプリ内リンクなど）
- 外部からの流入は、最初の数時間の視聴を後押しする。ただし、**その動画に興味がない人を大量に連れてくると、維持率が下がり、逆効果になる**ことがある。
- 攻略法：関心が一致する場所にだけ共有する（翻訳アプリの利用者、英語学習のコミュニティなど）。

### 流入経路の理想的な推移
| 段階 | 主な流入 | 状態 |
|-----|---------|------|
| 0〜3か月 | 検索 40%以上、Shorts、外部 | 検索で見つかる動画が再生を支える |
| 3〜6か月 | 検索 ＋ 関連動画が増える | 自分の動画同士、競合の動画とつながり始める |
| 6か月〜 | ブラウジング（ホーム）が最大になる動画が出る | 推薦システムに「この視聴者層に満足される」と学習された状態 |

## 3. 主要指標の読み方と目安

### 指標の定義と目安（教育・解説系の長尺）
| 指標 | 定義 | 目安 | 注意点 |
|-----|------|------|-------|
| **インプレッション** | サムネが画面に表示された回数（YouTube 内のみ） | 増加傾向か | 推薦システムが「試しに見せている」量。増えない＝初期反応が弱い |
| **インプレッションの CTR** | 表示された人のうちクリックした割合 | 2〜10%（多くは4〜6%） | インプレッションが増えると CTR は下がるのが普通。**CTR単体で判断しない** |
| **平均視聴時間** | 1回の視聴で見られた平均時間 | 長いほど良い | 動画の長さで変わるため、同じ長さの自分の動画と比べる |
| **平均再生率** | 動画全体のうち見られた割合 | 8〜12分で 35〜50% | 長い動画ほど下がる。最初の30秒の維持率とセットで見る |
| **最初の30秒の維持率** | 冒頭30秒後に残っている割合 | 65〜75%以上 | 低い＝サムネ・タイトルの約束と冒頭がズレている |
| **リピーター** | 過去にもチャンネルの動画を見た人 | 増加傾向 | 増えているとチャンネルに「固定ファン」がいる証拠 |
| **新しい視聴者** | 初めてチャンネルの動画を見た人 | 動画によっては多いほど良い | 新しい視聴者が多い動画＝推薦で外に広がっている |
| **登録者増／1,000回視聴** | 視聴が登録につながった割合 | 5〜15人 | 低い＝動画は見られているがチャンネルの価値が伝わっていない |
| **終了画面の CTR** | 終了画面の要素がクリックされた割合 | 高いほど良い | 次の動画への流れができているか |

※目安は一般的な傾向で、ジャンルや動画の長さで大きく変わります。**最も信頼できる比較対象は「自分の過去の動画」**です。Studio の「通常の範囲」表示（自分のチャンネルの過去動画との比較）を使ってください。

### 指標の組み合わせ診断
| CTR | 維持率 | 状態 | 打ち手 |
|-----|-------|------|-------|
| 高い | 高い | 推薦に乗りやすい理想の状態 | 同じ型・テーマで続編、シリーズ化 |
| 高い | 低い | クリックされるが期待外れ（釣り状態） | 冒頭で約束を回収。タイトルを内容に合わせる |
| 低い | 高い | 中身は良いが見つけてもらえない | サムネ・タイトルを差し替え（テストと比較） |
| 低い | 低い | 企画そのものが弱い | 企画を作り直す。この型を続けない |

### インプレッションが伸びない時の確認順
1. **公開後24〜48時間の CTR と維持率**を、自分の過去動画の通常範囲と比べる
2. **トラフィックソース**：どこからのインプレッションが止まっているか
3. **新しい視聴者の割合**：既存視聴者にしか届いていないか
4. 企画が登録者の関心とズレていないか（登録者が反応しないと、外への広がりも弱くなりやすい）

## 4. 投稿頻度

### 公式に言われていること
- 投稿頻度そのものが直接ランキングを上げたり下げたりするわけではない、と YouTube は説明しています。
- 一方で、**継続的に投稿するチャンネルの方が、視聴者が戻ってきやすく、学習の機会（データ）も増える**のは確かです。

### 推奨する頻度（週8〜10時間の場合）
| 形式 | 頻度 | 理由 |
|-----|------|------|
| 長尺 | **週1本・同じ曜日と時間** | 品質を落とさず続けられる上限。視聴者が「水曜は新作」と覚える |
| Shorts | 週3本 | 発見の入口。長尺の切り抜きで負担を抑える |
| コミュニティ投稿 | 週1〜2回 | 登録者との接点を保ち、次の動画の初期反応を作る |

### 頻度を決めるルール
- **品質を落としてまで頻度を上げない**：低品質な動画が続くと、登録者の反応が鈍り、次の動画の初期反応も弱くなる
- **頻度を上げてよい条件**：直近4本の CTR と平均再生率が通常範囲以上で、かつストックが2本以上ある時
- **休む時は予告する**：コミュニティ投稿で「来週はお休み、再来週に〇〇を公開」と伝える。休止そのものでチャンネルが罰せられることはない
- **公開時間**：最初は視聴者が見やすい時間（平日19時など）に固定し、30日後に Studio の「視聴者がオンラインの時間帯」の **1〜2時間前** に調整する（公開直後の処理・反映時間を見込む）

## 5. テスト方法

### 5-1. サムネイル・タイトルのテスト
- **YouTube Studio の「テストと比較（Test & Compare）」**：最大3つのサムネ（対応している場合はタイトルも）を同時にテストし、**総再生時間が最も多いもの**を勝者として選ぶ機能。CTR だけでなく視聴時間で判定されるため、釣りサムネが勝ちにくい。
- 使い方：
  1. 1本につき3案を用意（構図の型を変える：比較×○ / 驚き顔 / ランキング）
  2. 公開時からテスト開始
  3. 結果が出たら、勝った案の「型」を記録する（例：「比較×○型が2本連続で勝利」）
- **手動テスト**（機能が使えない場合）：公開から7日後に CTR が通常範囲より低ければサムネを差し替え、その後7日間と比較する。同時に2つ以上変えない。

### 5-2. 1週1実験のルール
| ルール | 内容 |
|-------|------|
| 変数は1つ | 「冒頭のフックの型」だけを変える、など |
| 比較対象を決める | 直近4本の平均、または同じカテゴリの過去動画 |
| 成功基準を先に書く | 「30秒維持率が+5ポイント以上」など |
| 最低3回試す | 1本の結果は偶然の可能性が高い。3本続けて同じ傾向なら採用 |
| 記録する | `templates/kpi-tracker.csv` の「実験内容」「結果・学び」欄 |

### 5-3. 優先して試すべき実験リスト
| 優先 | 実験 | 見る指標 |
|-----|------|---------|
| 1 | サムネの型（比較×○ vs 驚き顔 vs ランキング） | CTR、テストと比較の結果 |
| 2 | フックの型（結果見せ vs 警告 vs 問い） | 30秒維持率 |
| 3 | 動画の長さ（8分 vs 12分） | 平均視聴時間、総再生時間 |
| 4 | タイトルの型（警告 vs ランキング vs 謎解き） | CTR、検索流入 |
| 5 | 中盤CTAの位置（30% vs 50%） | 登録者増／1,000回視聴 |
| 6 | 最後のCTA（特定の動画 vs 再生リスト） | 終了画面 CTR |
| 7 | Shorts の長さ（20秒 vs 40秒） | 視聴率、平均再生率 |

### 5-4. ストーリーテスト（Shorts で企画を先に試す）
長尺を作る前に、そのテーマの要点を Shorts にして公開し、反応が良かったテーマを長尺にする。制作コストの低い Shorts で需要を確かめてから、時間のかかる長尺に投資できる。

## 6. 視聴者を登録者に変える方法

### 登録までの流れ
```
動画を見つける → 1本見て満足する → 「次も見たい」と思う → チャンネルの約束を知る → 登録する → 通知・ホーム画面で次の動画を見る
```
登録は「この先も価値がある」と確信した時に起きます。**1本の動画の満足だけでは不十分で、「このチャンネルは次も役に立つ」と分かることが必要です。**

### 登録率を上げる10の施策
| # | 施策 | やり方 |
|---|------|-------|
| 1 | **チャンネルの約束を明確にする** | バナー・概要欄・動画の冒頭で「AI英語をそのまま送らないための検証チャンネル」と一貫して伝える |
| 2 | **価値を届けてから頼む** | 中盤（価値を1〜2個届けた直後）に5秒以内で。冒頭では頼まない |
| 3 | **登録する理由を言う** | 「登録してください」ではなく「次の検証も届きます」と、登録の得を伝える |
| 4 | **シリーズ化する** | 「AI翻訳ラボ」「訳せない日本語」など続きものにすると「次も見たい」が生まれる |
| 5 | **2本目を見てもらう** | 終了画面・最後のCTA で特定の1本へ。**2本見た人は登録しやすい** |
| 6 | **再生リストを整える** | カテゴリ・シリーズごとに作り、順番を「入門→応用」にする |
| 7 | **チャンネルページを整える** | 未登録者向けの予告編（60秒）、おすすめのセクション（人気動画・シリーズ） |
| 8 | **透かしの登録ボタン** | Studio のカスタマイズ → ブランディング → 動画の透かし |
| 9 | **コメントに返信する** | 最初の1,000人までは全件返信。関係ができると登録とリピートにつながる |
| 10 | **固定コメントで問いかける** | 「あなたならどう訳す？」→ 次の動画で取り上げる（参加した人は戻ってくる） |

### 登録者をリピーターに変える
- **同じ曜日・同じ時間に公開**：視聴者の習慣になる
- **コミュニティ投稿**：次の動画のテーマをクイズや投票で予告し、公開時の初動を作る
- **登録者が反応する企画を続ける**：登録者が見ない動画が続くと、ホーム画面で表示されにくくなる
- **視聴者参加企画**（視聴者添削など）：自分の投稿が取り上げられるかもしれないという理由で戻ってくる

## 7. 最適化の実行リスト

### 公開前
- [ ] 企画が「4つのテスト」を通っている（[`10-production-system.md`](10-production-system.md) 2章）
- [ ] 検索系の動画は、サジェストに出る言葉をタイトルの前半に入れた
- [ ] サムネ3案を作り、テストと比較の準備をした
- [ ] 字幕を修正した（自動字幕の誤りを直す）
- [ ] チャプターを入れた（説明欄の最初のタイムスタンプは 00:00）
- [ ] 終了画面とカードで次の1本を指定した
- [ ] 再生リストに追加した

### 公開後 48 時間
- [ ] 最初の1時間はコメントにすべて返信
- [ ] 24時間後：CTR と30秒維持率を通常範囲と比較
- [ ] 48時間後：維持率グラフの最大の谷を記録し、原因を1行で書く
- [ ] 関連する Shorts を公開して関連動画リンクで本編へ誘導

### 公開後 7 日
- [ ] テストと比較の結果を記録
- [ ] トラフィックソースを確認（どの経路が伸びたか）
- [ ] 登録者増／1,000回視聴を記録
- [ ] 伸びた動画は「続編」「別の角度」の企画を企画バンクに追加

### 毎月：過去動画の見直し（成長の隠れた源泉）
- [ ] 過去90日で**インプレッションはあるのに CTR が低い動画**のサムネ・タイトルを差し替える
- [ ] **検索流入が多い動画**の説明文・チャプターを改善し、関連動画へのリンクを追加
- [ ] 伸びた動画の終了画面を、最新の関連動画に更新
- [ ] 再生リストの順番を見直す

## 8. よくある誤解

| 誤解 | 実際 |
|-----|------|
| タグを大量に付けると検索で上位に出る | YouTube はタグの役割は小さいと説明している。誤字が多い言葉などの補助程度 |
| 投稿を休むとアルゴリズムに罰せられる | 罰則はない。ただし視聴者の習慣が途切れるので、予告して休む |
| 公開時間が最も重要 | 影響は小さい。視聴者が多い時間に合わせる程度で十分 |
| Shorts を出すと長尺が伸びなくなる | 評価はほぼ別々。ただし Shorts から来た登録者が長尺を見ない場合、長尺の初期反応が弱く見えることはある |
| 伸びなかった動画は削除して出し直すべき | 削除しても良い影響はない。サムネ・タイトルの差し替えを先に試す |
| 長い動画ほど有利 | 視聴時間は大切だが、**内容に対して長すぎると維持率が下がる**。必要な長さにする |
| 登録者数が多いほど推薦される | 推薦は動画ごとの視聴者の反応で決まる。登録者が少なくても伸びる動画はある |

## 9. 成長戦略のまとめ（段階別）

### 毎週の判断に使う3つの問い
1. **今週の動画は、誰に向けて作ったか？**（視聴者が明確でないと、推薦システムも見せる相手を見つけられない）
2. **その人はクリックしたか、最後まで見たか、次の動画も見たか？**（CTR・維持率・終了画面）
3. **来週は何を1つだけ変えるか？**（1週1実験）
