# 16. 90日間アクションプラン

ゼロから収益化要件に向けて、90日間で「型・データ・ファン・収益の土台」を一気に作るための、週ごと・日ごとの実行計画です。
これまでのファイル（企画は [`09`](09-first-100-videos.md)、制作は [`10`](10-production-system.md)・[`13`](13-ai-production-workflow.md)、分析は [`15`](15-performance-analytics.md)、収益化は [`14`](14-monetization-system.md)）を、**いつ何をやるか** の順番に並べ直したものです。

> **日付について**：準備週（Week 0）を 2026年10月12日〜18日、Day 1 を 10月19日（月）としています。開始日がずれる場合は、週番号で読み替えてください。
> **前提**：週約6〜8時間（AI活用ワークフロー）、長尺は水曜19時、Shorts は月・金・土12時に公開。

---

## 1. 90日後のゴールを正直に設定する

フル収益化（登録者1,000人＋総再生時間4,000時間）を**90日で達成するのは、新規チャンネルでは簡単ではありません**。外れ値の動画が出れば可能性はありますが、それを前提にした計画は崩れやすくなります。
そこで、90日間のゴールを「**収益化までの道筋を確実にする状態**」に置き、2段階の目標を設定します。

| | 基本目標（達成すべき） | 挑戦目標（外れ値が出た場合） |
|---|---------------------|--------------------------|
| 登録者 | 300〜500人 | 1,000人以上 |
| 総再生時間（公開長尺の累計） | 1,000〜1,500時間 | 3,000時間以上 |
| 長尺 | 13〜15本 | 16〜18本 |
| Shorts | 39〜45本 | 50本以上 |
| メール/LINE リスト | 50〜100人 | 200人以上 |
| 勝ちパターン | 1つ確定 | 2つ確定 |
| 収益化 | 拡大版 YPP の申請準備完了 | 拡大版 YPP 申請（500人達成時） |

**90日後の本当の成果**：毎週止まらずに出せる制作システム、どの型が勝つかのデータ、反応してくれる最初のファン、収益化の準備がそろっていること。これがあれば、4〜9か月目に収益化要件へ到達するペースを作れます。

## 4. 生産性システム

### 4-1. ストックルール
- **常に1本以上の長尺を「予約済み」にしておく**（制作は公開の1週間前に終える）
- ストックが0になったら、その週は「最小限の週」（4-3）に切り替える

### 4-2. バッチ処理
同じ種類の作業をまとめると、切り替えの時間が減ります。
- 台本は2本分を同じ日に書く（フェーズ3）
- Shorts は3本を一度に切り出して予約
- サムネは月に1回、テンプレートをまとめて整える

### 4-3. 最小限の週（忙しい時・体調が悪い時の代替プラン）
「完璧な週」ができない時でも、**ゼロにしない**ことが最も大事です。
| 通常の週 | 最小限の週 |
|---------|----------|
| 長尺1本＋Shorts 3本＋SNS | ストックの長尺を公開＋Shorts 2本（過去の長尺の切り抜き） |
| 週次レビュー30分 | 指標の記録だけ（10分） |
| 毎日のコメント返信 | 公開日のコメント返信だけ |

### 4-4. 管理ボード
[`13`](13-ai-production-workflow.md) 8章の管理ボード（Notion / スプレッドシート）に、各週のタスクをチェックリストとして入れます。毎週日曜に翌週分を作成します。

### 4-5. エネルギー管理
- 創造的な作業（企画・台本）は、集中しやすい時間帯に置く
- 編集などの作業は、疲れていてもできる時間帯に置く
- 4週に1回は「軽い週」（視聴者添削や切り抜き中心）にして燃え尽きを防ぐ（Week 4・8・12 が目安）

## 7. パフォーマンスに基づく調整ルール

毎週・毎月のレビューで、次の「もし〜なら」ルールに従って計画を修正します。

### 7-1. 動画の指標による調整

| もし | なら |
|-----|-----|
| CTR が3本続けて中央値より低い | サムネの型を変える（テストと比較で別の型を試す）。タイトルの型も見直す |
| 30秒維持率が3本続けて65%未満 | 冒頭の構成を見直す（挨拶を削る、0〜3秒で約束を回収）。[`10`](10-production-system.md) 3・6章 |
| 平均再生率が30%未満 | 動画を短くする、項目を減らす、リフックを増やす |
| 登録率が5人/1,000回未満 | 中盤 CTA の位置と言い方を変える。シリーズ化を急ぐ |
| ある型の動画が2本続けて指数1.3以上 | その型を次の4週の50%以上にする |
| ある型の動画が3本続けて指数0.85以下 | その型を一時停止し、別の型に置き換える |
| 外れ値（視聴回数が中央値の3倍以上）が出た | 2週間以内に続編・別の角度の動画を出す。関連する Shorts を3本追加 |

### 7-2. チャンネル全体の進捗による調整

| もし | なら |
|-----|-----|
| Day 28 で登録者50人未満 | 検索型の動画の割合を増やす（検索サジェストに完全に一致するタイトル）。Shorts を週5本に |
| Day 56 で総再生時間400時間未満 | 10分以上の深掘り動画（謎解き・検証）を増やす。総再生時間が多い動画の続編を作る |
| Shorts の視聴回数は多いが登録者が増えない | Shorts の最後に長尺への導線（関連動画リンク）を必ず入れる。長尺の切り抜き Shorts の比率を上げる |
| 検索流入が20%未満 | タイトルの前半に検索語を入れる、説明文・チャプターを改善 |
| ホーム画面（ブラウジング）流入が5%未満のまま | おすすめ狙いの企画（好奇心・意外性）を月2本に増やす |
| 予定より大幅に上回っている | 頻度を上げる前に、ストックを2本に増やす。収益化の準備（[`14`](14-monetization-system.md)）を前倒し |

### 7-3. 自分の状態による調整

| もし | なら |
|-----|-----|
| 2週続けて制作が予定通りに終わらない | 動画を短くする、Shorts を2本にする、AI ワークフローの使い方を見直す。品質を落とす前に量を調整 |
| ストックが0になった | 次の週は「最小限の週」にして、ストックを1本作ることに集中 |
| 楽しくない・やる気が出ない | 自分が一番作りたい企画を1本入れる。数字を見るのを2週間休み、行動の KPI だけ見る |
