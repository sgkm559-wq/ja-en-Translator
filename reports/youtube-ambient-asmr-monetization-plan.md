# ぺんてぃ × 環境音/ASMR チャンネル 収益化レポート（1年計画）

作成日: 2026-10-13

---

## 0. 結論（先に要点だけ）

1. **今いちばん大きい論点は 2027年2月1日の YPP 条件引き上げ。** 新規申請は「登録者1,000人 + 直近365日で**8,000時間**（現在は4,000時間）」になる。ゼロから始めて2027年1月末までに現行条件を満たすのはほぼ不可能なので、**最初から8,000時間前提で計画する**のが現実的。
2. **静止画のスライドショーやループは、収益化審査で落ちるリスクが高い形式。** YouTube の「Generic or Repetitive Content（旧: Inauthentic Content）」ポリシーは、例として *image slideshows* や「テンプレートで量産したような動画」を挙げている。ぺんてぃを使うのは良い差別化だが、**動き（火のゆらぎ、雨粒、まばたき等）と、動画ごとに違うシーン・音作り**が必要。
3. **音は「自分で録る」のが最強だが、必須ではない。** ライセンスのはっきりした素材を重ねて加工すれば十分（3.2 を参照）。BGM が必要なら、YouTube オーディオライブラリ（Content ID で申し立てされない）か、Epidemic Sound などの有料サブスクを使う。AI 生成音楽は有料プランなら商用 OK だが、権利がまだ不安定なので主力にしない。
4. **1年の収益予測（広告のみ）**: 慎重ケースは **0円**（年内に収益化できない）、標準ケースは **約11万円**（9ヶ月目から収益化）、楽観ケースは **約70万円**（1本ヒットして5ヶ月目から収益化）。1年目は「収益化を通すまでの年」と割り切るのが妥当。
5. **需要はあるが、競争も激しい。** 雨・焚き火・作業用 BGM は常に需要がある一方、2026年は小規模な新規アンビエントチャンネルが大量に参入している。**「ぺんてぃ」というキャラの世界観**（Lofi Girl 型）で差別化するのが一番の勝ち筋。

> ⚠️ 前提の確認: 「ぺんてぃ」が**自分のオリジナルキャラ／自分のペット**であることを前提に書いている。他人のキャラクター（ファンアート含む）の場合は、権利者の許諾なしで収益化すると著作権侵害になり、Content ID の申し立てやチャンネル停止のリスクがある。Lofi Girl も最初はジブリのキャラを使っていて、チャンネルが削除された過去がある。

## 1. 収益化の条件とスケジュール

| 項目 | 現行（〜2027/1/31） | 2027/2/1 以降の新規申請 |
|---|---|---|
| 登録者 | 1,000人 | 1,000人 |
| 長尺の総再生時間 | 直近12ヶ月で4,000時間 | 直近365日で**8,000時間** |
| ショート（代替ルート） | 直近90日で1,000万回 | 直近90日で**2,000万回** |
| ファンファンディング（メンバーシップ等）の早期枠 | 登録者500人 + 3,000時間ほか | 変更なし |

- 日本は YPP の対象国。
- 再生時間に数えられるのは**公開中の長尺動画のみ**。限定公開・非公開・削除済みの動画、ショートの視聴時間は対象外。
- **収益化は遡らない**。承認されるまでに出た再生分は収益にならない。

**環境音ジャンルの特徴**: 1再生あたりの視聴時間が長いので、**再生時間はすぐ貯まる一方、登録者が伸びにくい**（BGM として流すだけで、チャンネル登録しない人が多い）。8,000時間よりも**登録者1,000人のほうがボトルネックになりやすい**。

## 2. オリジナリティとポリシー対策（ぺんてぃ活用法）

### 2.1 何が収益化 NG になりやすいか
- YouTube は2025年7月と2026年7月に、収益化ポリシーの文言を明確化した（新しいルールの追加ではなく、既存ルールの説明を直したもの）。名称は「Inauthentic Content」から「**Generic or Repetitive Content**」に変わった。
- 例として挙がっているのは **画像のスライドショー**、テンプレートで作ったストーリー、変化の少ない動画など。
- 判定は**チャンネル単位**。「同じチャンネルの動画を続けて見ると、どれも同じに感じる」状態が危ない。
- 一方で、**OP/ED の形式を揃えること**や、**コンセプトを統一したシリーズ**は、各動画の中身が違えば問題ないとされている。

### 2.2 ぺんてぃでの差別化（推奨）

| やること | 理由 |
|---|---|
| **1動画 = 1シーン**で、ぺんてぃを描き下ろす（例: 焚き火の前でうとうと／雨の窓辺で読書／深夜にキーボードを打つ） | 「同じ画像の使い回し」に見えないようにする |
| 静止画ではなく**数秒〜数十秒のアニメーションループ**にする（火のゆらぎ、雨のパーティクル、湯気、まばたき、しっぽ） | スライドショー扱いを避けられる。Lofi Girl も「ループなのにループに感じない」と言われている |
| シリーズ化する: 「ぺんてぃの冬キャンプ」「ぺんてぃの雨の日」など。概要欄に短いストーリー（2〜3行）を書く | 動画ごとに「物語や焦点の違い」があることを示せる |
| 音を毎回デザインし直す（雨＋焚き火＋遠雷、時間経過で雨が強くなる、など）。チャプターで「雨弱め→強め→止む」と構成する | 音の面でも変化を出す |
| 季節もの・時間帯もの（夜明け、クリスマス、梅雨） | 検索需要の波に乗れる |
| ショートでは「ぺんてぃの数秒アニメ＋音」を出し、長尺版へ誘導する | 登録者獲得の入り口になる（ショートの視聴時間自体は再生時間に数えられない） |

**制作のヒント**: 10〜30秒のシームレスなループ映像を1本作れば、ffmpeg で長尺化できる（例: `ffmpeg -stream_loop -1 -i loop.mp4 -i audio.wav -shortest -c:v copy -c:a aac out.mp4`）。編集は DaVinci Resolve（無料）で十分。ただし「同じループ映像＋違う音」だけを量産すると、上記ポリシーに引っかかる。**映像も毎回作ること。**

## 3. 音（環境音・BGM）の用意の仕方

### 3.1 選択肢の比較

| 方法 | 収益化 | Content ID リスク | コスト | おすすめ度 |
|---|---|---|---|---|
| **自分で録音**（キーボード、雨、焚き火、生活音） | ◎ 完全に自分の権利 | ほぼなし | 録音機 1〜3万円 | ★★★ 主力 |
| **YouTube オーディオライブラリ** | ◎ YPP で収益化 OK と明記 | Content ID で申し立てされない | 無料 | ★★★ BGM の第一候補 |
| **有料サブスク**（Epidemic Sound, Artlist など） | ◎ | チャンネルを登録しておけば申し立てを解除できる | 月額千〜数千円 | ★★☆ BGM を本格的に使うなら |
| **CC0 素材**（Freesound の CC0 など） | ○ | **誤検知の報告あり**（CC0 の音がテクノ曲として Content ID に引っかかった例） | 無料 | ★★☆ 補助として使う。ライセンス画面のスクショを保存しておく |
| **国内フリー素材**（効果音ラボ、DOVA-SYNDROME → 2026/9/15 から「OpenTracks」に名称変更） | ○ 基本は商用 OK | 曲ごとにライセンスが違う。クレジット表記が必要な場合あり | 無料 | ★☆☆ 曲ごとに規約を確認する |
| **CC BY-NC 素材** | ✕ 収益化動画では使えない | — | — | 使わない |
| **AI 生成**（Suno / Udio の有料プラン） | △ 有料プランなら商用利用可。無料プランで作った曲は後から課金しても商用不可 | 申し立ての報告あり。生成記録を保存しておく必要がある | 月 $10〜 | ★☆☆ 権利関係が不安定（訴訟が継続中。AI のみで作った曲は著作権が発生しない可能性があり、他人に流用されても止められない） |
| **作曲を外注**（ココナラ、SKIMA など） | ◎ 著作権の譲渡を契約書に明記すること | なし | 1曲 数千〜数万円 | ★★☆ 「ぺんてぃのテーマ」を1曲作ると、ブランドの資産になる |

### 3.2 推奨構成
- **環境音は録音しなくてもよい。** ライセンスのはっきりした素材を使い、**重ねて加工すれば**オリジナルの音として成立する。
  - 素材の入手先: YouTube オーディオライブラリの効果音タブ、Freesound（CC0 に絞って検索）、効果音ラボ、Epidemic Sound の SFX など。
  - **オリジナルにする工夫**: 複数の素材を重ねる（例: 雨・窓に当たる雨・遠雷・室内の残響）。EQ と音量の変化を時間軸で付ける（雨が強まる→弱まる、など）。こうすると、他のチャンネルとまったく同じ音にならず、Content ID の誤検知も起きにくくなる。
  - 録れるものだけ録る: キーボード音は室内で録れる。スマホの録音でも、静かな部屋なら十分使える。
  - 代用の録音（フォーリー）: セロハンやポリ袋をくしゃくしゃにすると焚き火のパチパチ音になる。紙や傘の上に米や塩を落とすと雨音になる。どちらも昔からの効果音の作り方。
  - プログラムでの音の合成: 雨や焚き火の音は、ノイズの合成でかなり作れる。完全に自分の権利になる。
  - **AI 動画ツールで生成した音**: 商用利用 OK の有料プランなら使ってよい。ただし次の点に注意する。
    - 利用規約で、音声も商用利用の対象に含まれているか確認する。
    - 数秒のクリップをそのまま繰り返すと、ループしているのが耳でわかる。複数回生成した音をクロスフェードでつなぎ、ランダムな順番に並べる。
    - 変な声や音楽が混ざっていないか、通して聞いて確認する。
    - 生成した日時と、課金していた証拠を保存しておく。
- **BGM 入りの回 = YouTube オーディオライブラリ**から始める。伸びてきたら Epidemic Sound に切り替えるか、オリジナル曲を外注する。
- **素材台帳を作る**: どの動画に、どの素材を、どのライセンスで使ったか（URL、ライセンスのスクショ、ダウンロード日）を記録しておく。Content ID の申し立てに異議を出すときに必要になる。
- 「BGM なし（環境音のみ）」と「BGM あり」の両方を出して、どちらがウケるか試す。睡眠用途では BGM なしのほうが好まれやすい。

## 4. 需要と競合

- **需要の根拠**: 雨・焚き火系の動画で伸びているのは「**雨 + 居心地のいい場所 + 睡眠／勉強という明確な用途**」の組み合わせ（チャンネル分析サイトの分析より）。長時間流されるため、再生時間を稼ぎやすいジャンルでもある。
- **キャラクター型の成功例**: Lofi Girl は、ループアニメのキャラクターがコミュニティの象徴になり、登録者は1,500万人を超えた（2026年2月時点）。そこから音楽レーベル、Discord、企業コラボにまで広がっている。「**キャラ × 環境音**」は実績のある型。
- **競合**: 2026年に開設された小規模な雨・焚き火・キャビン系のチャンネルが多数あり（登録者が数十〜千人程度のものが大半）、供給過多ぎみ。AI で量産された似たような動画も多い → **ただの雨の動画では埋もれる**。キャラと世界観で選ばれる理由を作ることが必須。
- **狙い目のキーワード（日本語）**: 「作業用BGM」「睡眠用」「勉強用」「焚き火 ASMR」「雨音 1時間/3時間/8時間」「キーボード ASMR」「カフェ 環境音」。英語タイトルを併記すると海外の視聴者も取れて、広告単価も上がりやすい（例: `Cozy Rain & Fireplace with Penty 🔥 3 Hours for Sleep / Study`）。
- **注意点**: 寝ている途中のミッドロール広告は視聴者に嫌われやすい。広告を入れる位置（冒頭に集中させる、など）を試して調整する。

## 5. 1年計画と収益予測

### 5.1 前提（すべて仮定。実データが出たら更新する）

| パラメータ | 慎重 | 標準 | 楽観 |
|---|---|---|---|
| 1再生あたりの視聴時間 | 0.15時間（9分） | 0.2時間（12分） | 0.25時間（15分） |
| 登録率（登録者 ÷ 累計再生） | 0.5% | 0.8% | 1.0% |
| RPM（1,000再生あたりの手取り） | ¥250 | ¥400 | ¥500 |

- RPM の根拠: 海外の睡眠・雨音系は **$2〜6**（推定値。ブログによっては ASMR で $10 超という主張もある）。日本の AdSense の平均 RPM は約 $3.18（2025年後半の実績ベース）。エンタメ系は約250円とされている。日本の視聴者中心なら低めに見積もるのが安全。
- 投稿ペース: 長尺（1〜3時間）を週2本 + ショートを週2〜3本。

### 5.2 月別の再生数と到達予測

**標準ケース**

|---|---|---|---|---|---|
| 1 | 1,000 | 1,000 | 200h | 8 | 立ち上げ |
| 2 | 3,000 | 4,000 | 800h | 32 | |
| 3 | 6,000 | 10,000 | 2,000h | 80 | |
| 4 | 10,000 | 20,000 | 4,000h | 160 | ※ 2/1 以降は8,000時間が必要 |
| 5 | 15,000 | 35,000 | 7,000h | 280 | |
| 6 | 20,000 | 55,000 | 11,000h | 440 | 再生時間はクリア／500人でメンバーシップ解禁目前 |
| 7 | 30,000 | 85,000 | 17,000h | 680 | |
| 8 | 40,000 | 125,000 | 25,000h | **1,000** | 申請（審査に約1ヶ月） |
| 9 | 50,000 | 175,000 | — | 1,400 | **収益化** ¥20,000 |
| 10 | 60,000 | 235,000 | — | 1,880 | ¥24,000 |
| 11 | 75,000 | 310,000 | — | 2,480 | ¥30,000 |
| 12 | 90,000 | 400,000 | — | 3,200 | ¥36,000 |

→ **1年目の広告収益: 約11万円**。2年目は月4〜10万円のペースが見込める。

**楽観ケース**（3ヶ月目に1本がおすすめに乗って伸びる）
- 月間再生: 2k → 8k → 30k → 80k → 100k → … → 250k（12ヶ月目）
- 4ヶ月目に登録者1,000人と8,000時間をクリア → 5ヶ月目から収益化
- 5〜12ヶ月目の広告収益: ¥50k → ¥125k/月、**合計 約70万円**

**慎重ケース**
- 月間再生: 300 → 8,000（12ヶ月目）、累計は約4.5万再生、登録者は約220人
- 再生時間（約6,700時間）も登録者も届かず、**1年目は広告収益0円**
- → 6ヶ月目の時点でこのペースなら、方向転換する（下の 5.4 を参照）

### 5.3 フェーズ別のやること

| 期間 | 目標 | アクション |
|---|---|---|
| **0〜1ヶ月** | 型を作る | ぺんてぃのループアニメを3種類（焚き火／雨／キーボード）作る。音の録音と素材台帳の作成。チャンネル名、アイコン、バナー、サムネのテンプレートを決める。最初の6本を公開 |
| **1〜3ヶ月** | どれがウケるか検証する | 週2本の長尺 + ショート。長さ（1h/3h/8h）、BGM あり／なし、日本語／英語タイトルで A/B テストする。視聴維持率と登録率を見る |
| **3〜6ヶ月** | 当たった型を伸ばす | 伸びたシーンをシリーズ化する。季節ものを投入（冬の焚き火、クリスマス、梅雨）。コミュニティ投稿でぺんてぃの日常を見せる。500人に届いたらメンバーシップを検討 |
| **6〜9ヶ月** | 収益化申請 | 1,000人 / 8,000時間をクリアしたら申請。審査に備えて、**チャンネル全体で動画ごとの違いがはっきりわかる状態**にしておく |
| **9〜12ヶ月** | 収益を広げる | ぺんてぃのテーマ曲を作る。広告以外の収益源（下記）を立ち上げる |

### 5.4 広告以外の収益源（キャラがあるからこそできるもの）
- **音源の配信**（Spotify など）: 自分で録った環境音をアルバムとして配信する。ただし Spotify は、ノイズ系の短いトラックや再生数の少ない曲には支払わないルールがある。配信前に最新の条件を確認すること。
- **ぺんてぃのグッズ／LINE スタンプ／壁紙**（BOOTH、SUZURI など）
- **メンバーシップ**（登録者500人から使える）: 限定の長尺版、広告なし版、ぺんてぃの描き下ろし
- **ハイレゾ音源や BGM 素材の販売**（自分で録った音だけ。DOVA の音源など他人の素材の再配布は不可）

### 5.5 方向転換の目安
- 3ヶ月目に月5,000再生未満 → サムネとタイトルを作り直す。英語圏向けに比重を移す
- 6ヶ月目に登録者200人未満 → ショートを強化する。ぺんてぃのストーリー性を強める（音なしでも見られる短いアニメなど）
- 収益化の審査で落ちた場合 → 不承認の理由は「チャンネル全体の再利用・繰り返し」であることが多い。映像のバリエーションを増やしてから、30日後に再申請する

## 7. 注意・リスクのまとめ
- 公式の規約ページ（YouTube ヘルプ、各素材サイト、Suno の利用規約）は頻繁に変わる。この調査では直接取得できなかったものもあるので、**使う前に必ず最新版を確認すること**。
- RPM の数値は外部ツールやブログの推定値。実際の値は YouTube Studio の収益タブで確認し、この予測表を更新する。
- AI 生成画像のぺんてぃを量産するのは避ける。手描き、または自分で作ったものを主体にすると、ポリシー上もブランド上も強い。
