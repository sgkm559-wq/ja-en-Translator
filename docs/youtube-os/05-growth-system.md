# 05. 成長システム

## 1. 3 つの発見経路と役割分担

| 経路 | 仕組み | 効く柱・形式 | 初期に重視する度合い |
|------|-------|-------------|------------------|
| **検索** | キーワードと一致する動画を表示。長期的に再生が積み上がる | 柱②（L2）、柱③ | ◎ 0〜3か月の土台 |
| **ブラウジング／おすすめ** | CTR と満足度が高い動画を拡散 | 柱①（L1）、外れ値企画 | ○ 毎月 1 本は狙う |
| **関連動画** | 視聴中の動画の横・後に表示 | シリーズ、競合の人気テーマ | ○ 競合ヒットの「別解」を出す |
| **Shorts フィード** | スワイプで新規層に露出 | S1〜S3 | ◎ 登録者の入口 |

新規チャンネルはおすすめのデータがないため、**最初の 10〜20 本は「検索で見つかる動画」を中心に**し、視聴者データを蓄積させる。

## 2. 成長フライホイール

```
 Shorts（発見） ──→ 長尺（信頼・総再生時間）──→ 登録・通知
     ↑                                         │
     │                                         ↓
 長尺の切り抜き ←── コメント・質問 ←── コミュニティ投稿・ライブ
                         │
                         ↓
                   次の企画バンク
```

- 長尺 1 本 → Shorts 2〜3 本に分解（S3）。
- コメントの質問 → 次の L4（視聴者添削）や L2 の企画に。
- 再生リストで「柱ごとの連続視聴」を設計し、セッション時間を伸ばす。

## 3. キーワード・企画リサーチの手順（週 30 分）
1. YouTube 検索窓のサジェスト：「英語 メール」「〇〇 英語で」＋ あ〜ん・a〜z。
2. 競合の外れ値動画（平均の 3 倍以上）をリスト化 → **同テーマ・別角度** の企画を作る。
3. Google トレンド・X のトレンドから時事ネタ（新しい AI 翻訳ツールのリリースなど）を拾う。
4. 企画ごとに `需要（1-5）× 差別化（1-5）× 制作容易性（1-5）` でスコア化し、上位から制作。

## 4. 外部流入
- **X / Threads**：毎日 1 投稿（Before/After の画像 1 枚＋動画リンク）。
- **既存資産の活用**：翻訳アプリ内・README・ストアページに「使い方・解説動画」として YouTube を埋め込む。アプリ利用者 → 視聴者の導線は最も質の高い流入。
- **コラボ**：登録者が同規模の英語・日本語学習チャンネルと「お互いの添削」企画（月 1 本を 3 か月目以降）。
- **Reddit / 知恵袋**：質問への回答で関連動画を自然に紹介（宣伝目的の投稿はしない）。

## 5. 成長実験ループ（毎週 1 実験）

| 項目 | 記入例 |
|------|-------|
| 仮説 | 「サムネに顔を入れると CTR が上がる」 |
| 変数（1 つだけ） | サムネの顔の有無 |
| 指標 | 公開 7 日 CTR |
| 成功基準 | 直近 4 本平均 +1.0pt |
| 結果 | |
| 判断 | 採用 / 却下 / 再テスト |

実験候補の例：タイトル型の比較、動画尺（8分 vs 12分）、公開時間、Shorts の尺、冒頭 Hook の型、終了画面の誘導先。

## 6. 段階別の成長目標

| フェーズ | 期間 | 登録者 | 主な焦点 |
|---------|------|--------|---------|
| 0. 立ち上げ | 0〜30日 | 0 → 100 | 型の確立、検索動画 4〜5 本、Shorts 12 本 |
| 1. 発見 | 31〜90日 | 100 → 500 | 勝ちフォーマット特定、外れ値狙い月 1 本 |
| 2. 加速 | 91〜180日 | 500 → 1,000+ | シリーズ量産、コラボ、ライブ開始 |
| 3. 収益化 | 180日〜 | 1,000+ / 4,000h | YPP 申請、収益源の多角化 |

> 数値は一般的な教育系新規チャンネルの「良好ケース」の目安。外れ値 1 本で大きく前倒しされることも、逆に 9〜12 か月かかることもある。遅れていても「週次サイクルを止めない」ことが最大の成功要因。
