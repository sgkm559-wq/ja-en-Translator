# 11. 企画パッケージ10本（成長スコア上位）

[`09-first-100-videos.md`](09-first-100-videos.md) の上位から10本を、[`10-production-system.md`](10-production-system.md) の手順で制作できる状態にしたものです。
各企画に、コンセプト・フック・タイトル案・サムネ案・オープニング・構成・維持の仕掛け・CTA と、**なぜ視聴者を引きつけ、見続けさせるのか** の分析を付けています。
★印の3本は [`scripts/`](scripts/) に完全台本があります。

> **AIツールの出力について**：企画内の「AIの訳」は想定例です。撮影時に実際の出力を取得し、取得日を画面に表示してください。
> 想定と違う結果が出た場合は、その結果に合わせて構成を組み替えます（予想外の結果はむしろ良い素材です）。

## ★1. 「お疲れ様です」をAI翻訳5社に訳させたら全滅した

| 項目 | 内容 |
|------|------|
| コンセプト | 日本人が毎日使う「お疲れ様です」を5つのAI翻訳にかけ、場面ごとに採点。正しい英語を場面別に教える |
| ストーリー型 | 型A：検証ストーリー |
| 尺 | 9〜10分 |
| フック | 「AI翻訳5社に『お疲れ様です』を訳させました。……全部、使えませんでした。」＋ 5つの訳が画面に並び、次々に赤× |
| タイトル案 | ①「お疲れ様です」をAI翻訳5社に訳させたら全滅した ②「お疲れ様です」を英語で言えますか？AI5社が全滅 ③ そのメールの「Thank you for your hard work」、ネイティブには変です |
| サムネ | ロゴ全滅型：5つのツール名に赤×、中央に大きく「全滅」、右下に小さく「お疲れ様です」 |
| オープニング | 0〜3秒：5つの訳文が並び赤×が連続 → 3〜8秒：フック → 8〜15秒：「場面別の正しい言い方を4つ教えます」→ 15〜25秒：翻訳アプリ開発者として → 25〜30秒：「4つ目は、日本人のほぼ全員が間違えています」 |
| 構成 | 実験条件 → AIの訳5つを採点 → なぜ全滅するのか（場面が書かれていない）→ 場面別の正解4つ → 実用ルール |
| 維持の仕掛け | 採点の前に「あなたなら何点？」と3秒考えさせる／弱い結果から順に出す／画面隅に「場面 1/4」 |
| CTA | 中盤：「あなたの会社の『お疲れ様』は何の意味で使っていますか？コメントで」／最後：「もっと訳せないのが『よろしくお願いします』です」→ ★3へ |

**なぜ効くのか**
- **当事者性が最大級**：視聴者のほぼ全員が今日も使った言葉。「自分のことだ」と0.5秒で分かる。
- **権威の逆転**：「AIは正しい」という前提が崩れる。崩れる瞬間を見たい気持ちがクリックを生む。
- **「全滅」の強さ**：一部失敗ではなく全部失敗という極端さが好奇心を最大化する。ただし動画内で実際に「そのまま使えるものがない」ことを示せる時だけ使う。
- **見続ける理由**：「では何と言えばいいのか」という問いが、場面別の正解4つを見終わるまで解決しない。

## 2. ChatGPTが書いた英語メール、ネイティブに見せたら「失礼」と言われた理由

| 項目 | 内容 |
|------|------|
| コンセプト | ChatGPT に日本語の依頼メールを英訳させ、英語ネイティブ（同僚・知人・オンライン講師など）に採点してもらう。指摘された箇所を1つずつ直す |
| ストーリー型 | 型A：検証 ＋ 型D：ビフォーアフター |
| 尺 | 10〜12分 |
| フック | ネイティブの反応（「これ、ちょっと命令っぽいね」）を冒頭に3秒だけ見せる → 「ChatGPTが書いた、一見完璧なメールです。どこが問題か分かりますか？」 |
| タイトル案 | ① ChatGPTの英語メール、ネイティブに見せたら「失礼」と言われた ② AIが書いた英語メール、ネイティブの採点は何点？ ③ 完璧に見えるAI英語メールの3つの落とし穴 |
| サムネ | 驚き顔＋1行型：メール画面の一部に赤線、吹き出しで「Rude…?」、大きく「何点？」 |
| オープニング | ネイティブの反応 → 元のメールを画面に → 「間違い探しです。3つあります」→ 開発者として → 「3つ目は、文法は完璧なのに失礼な理由です」 |
| 構成 | 元メール提示 → 視聴者に予想させる → ネイティブの指摘1・2・3（弱→強）→ 修正版 → 並べて比較 → ChatGPTへの指示の改善 |
| 維持の仕掛け | 「間違いは3つ」と数を予告（ゴールが見える）／各指摘の前に一時停止の促し／最後に「直したメールで何点に上がったか」を保留 |
| CTA | 「あなたのメールも添削します。コメントに英文を」→ 視聴者添削シリーズ（#36）の素材集めに直結 |

**なぜ効くのか**
- **第三者の審判**：自分ではなくネイティブが判定するため、結果に説得力と意外性がある。
- **間違い探しの参加感**：視聴者が自分で答えを探すことで、受け身の視聴が能動的になり維持率が上がる。
- **「点数」という未解決の問い**：修正後の点数が最後まで明かされない。
- **注意**：ネイティブの協力者は本人の同意を得て出演してもらい、反応を演出しない。

## ★3. 「了解しました」の英語9パターン【失礼な順ランキング】

| 項目 | 内容 |
|------|------|
| コンセプト | 「了解しました」の英語訳9つを、上司・顧客に使った時の印象で「誤解されやすい→丁寧」の順に並べる |
| ストーリー型 | 型B：ランキング |
| 尺 | 8〜9分 |
| フック | 「上司に『OK』と返していませんか？」→「『了解しました』の英語9つ、上司に使うと危ない順に並べました」 |
| タイトル案 | ①「了解しました」の英語9パターン【失礼な順ランキング】 ② 上司に「Got it」はアウト？「了解しました」の英語9選 ③「Noted」は冷たい？「了解しました」の正しい英語 |
| サムネ | ランキング型：「失礼 ←→ 丁寧」の矢印に OK / Got it / Noted…を並べ、一番右だけ「？？？」 |
| オープニング | 矢印の図が出る → フック → 「最後まで見れば、相手と場面に合わせて選べるようになります」→ 「1位は、ほとんどの人が知らない言い方です」 |
| 構成 | 判断基準（相手・場面・温度）→ 9〜4位をテンポよく → 中間で「ここまでのまとめ図」→ 3〜1位をじっくり → 使い分け表 |
| 維持の仕掛け | 画面隅に「9/9→1/9」のカウントダウン／中間で全体図を見せて現在地を示す／1位を最後まで隠す |
| CTA | 中盤：「使い分け表は概要欄に」／最後：「では、断る時はどう言うか。それはこの動画で」→ #14 |

**なぜ効くのか**
- **ランキングは最後まで見る理由が構造に組み込まれている**：1位を知るまで終われない。
- **検索とおすすめの両方に強い**：「了解しました 英語」は検索され続けるキーワードで、「失礼な順」という角度がおすすめでのクリックも生む。
- **自分の癖を確かめたい気持ち**：「自分がいつも使っている言葉は何位か」を知りたくなる。

## 4. DeepL vs Google翻訳 vs ChatGPT：ビジネスメール対決【翻訳アプリ開発者が採点】

| 項目 | 内容 |
|------|------|
| コンセプト | 同じ日本語メール3通（依頼・お礼・謝罪）を3つのAIに訳させ、5項目（正確さ・丁寧さ・自然さ・簡潔さ・誤解リスク）で採点 |
| ストーリー型 | 型A：検証（3ラウンド制のトーナメント） |
| 尺 | 12〜14分 |
| フック | 「AI翻訳、結局どれを使えばいいのか。3ラウンドで決着をつけます。最終ラウンドで大逆転が起きました。」 |
| タイトル案 | ① DeepL vs Google翻訳 vs ChatGPT：ビジネスメール対決 ② 結局どのAI翻訳が一番？仕事メールで3社比較 ③ 翻訳アプリ開発者が本気で採点：AI翻訳ランキング |
| サムネ | 採点表型：3つのツール名と点数、1つだけ「？？点」 |
| オープニング | 3つの訳が並ぶ画面 → フック → 採点基準を5秒で → 開発者として → 「最終ラウンドの謝罪メールで、順位がひっくり返ります」 |
| 構成 | ルール説明 → 第1ラウンド：依頼 → 第2ラウンド：お礼 → 中間順位 → 第3ラウンド：謝罪 → 最終結果 → 用途別のおすすめ |
| 維持の仕掛け | ラウンド制で区切り、毎回「現在の順位」を表示／最終ラウンドの逆転を冒頭で予告 |
| CTA | 「あなたはどれを使っていますか？」コメント促進（投票型で返信しやすい） |

**なぜ効くのか**
- **対決は結果を知るまで離れられない**：スポーツ中継と同じ構造。
- **実用的な答え**：視聴者は「結局どれを使えばいいか」を知りたい。購入・利用の判断に直結するため検索も強い。
- **「逆転」の予告**：最後のラウンドまで見る理由を冒頭で作る。実際に逆転が起きない場合は予告しない。
- **注意**：ツールのバージョンと取得日を明記。特定サービスを不当に貶めず、採点基準を公開する。

## ★5. 「よろしくお願いします」が英語に存在しない本当の理由

| 項目 | 内容 |
|------|------|
| コンセプト | 「よろしくお願いします」に1対1の英語がない理由を、日本語と英語の仕組みの違いから謎解き形式で説明し、場面別の言い方を教える |
| ストーリー型 | 型C：謎解き |
| 尺 | 10〜11分 |
| フック | 「『よろしくお願いします』。日本人が1日に何度も使うこの言葉、英語には存在しません。そして、それには理由があります。」 |
| タイトル案 | ①「よろしくお願いします」が英語に存在しない本当の理由 ② なぜ「よろしくお願いします」は英語に訳せないのか ③ AIも訳せない日本語「よろしくお願いします」の正体 |
| サムネ | 比較×○型：「Yoroshiku onegaishimasu = ？」に大きな赤い「？」、横に小さく「AIも×」 |
| オープニング | AIの訳（例：Thank you in advance / Best regards / Nice to meet you）が場面とズレて表示 → フック → 「理由が分かると、どんな場面でも自分で英語を選べるようになります」→ 「鍵は、日本語が『何を』お願いしているかを言わないことです」 |
| 構成 | 謎の提示 → よくある誤答（AIの訳）→ 手がかり1：日本語は「何を」を言わない → 手がかり2：関係を作る言葉 → 答え：英語は具体的な行動を言う → 場面別の言い方5つ |
| 維持の仕掛け | 謎→手がかり→答えの順で、答えを中盤以降まで保留／手がかりごとに「ここで気づいた人はすごい」 |
| CTA | 「あなたの職場で一番訳しにくい日本語は？」→ 次の謎解き動画の企画に |

**なぜ効くのか**
- **当たり前の言葉に謎があるという意外性**：毎日使う言葉なのに理由を知らない。知的好奇心が強く働く。
- **ハウツーではなく「理解」を届ける**：理由が分かると応用できるため満足度が高く、高評価・共有が増える。
- **チャンネルの差別化に直結**：言語の仕組みを開発者の視点で語れることが、他の英語チャンネルとの違いになる。
