# 01. 分析：ニッチ・視聴者・競合・リソース・目標

## 1. ニッチ分析

### 評価スコアカード（各 1〜5 点、合計 20 点以上で GO）

| 軸 | 問い | 仮ニッチの採点 |
|----|------|----------------|
| 需要 | 検索ボリュームと「おすすめ」で回る話題があるか | 5（英語学習は日本で最大級の教育ジャンル） |
| 収益性（RPM） | 広告主が高単価で出稿するか | 4（教育・英会話スクール・アプリ・転職が出稿） |
| 競合の隙 | 大手が拾えていない切り口があるか | 3（大手は多いが「翻訳・ニュアンス」特化は薄い） |
| 持続性 | 100 本以上ネタが続くか | 5（表現・場面・文化差は無限） |
| 適性 | あなたが続けられ、独自性を出せるか | 4（翻訳アプリ開発者という独自の立場） |
| **合計** | | **21 / 25 → GO** |

### ニッチの絞り方（「広すぎ」は最大の失敗要因）
`大テーマ` → `誰向け` → `どの場面` → `どの切り口` の 4 段で絞る。

- 例：英語 → 日本人社会人 → 仕事のメール・会議 → 「直訳すると失礼になる表現の言い換え」
- 最初の 30 本はこの狭い範囲で打ち、反応が良い方向へ徐々に広げる（「狭く入って広く出る」）。

## 2. 視聴者分析

### ペルソナ（仮）

**ペルソナA：ユウタ（32歳・IT企業勤務）**
- 状況：外資系との会議が増え、Slack やメールを翻訳ツールに頼っているが「これで失礼じゃない？」と不安。
- 検索語：「英語 メール 丁寧」「了解しました 英語」「翻訳 ツール 不自然」
- 視聴タイミング：通勤中（スマホ・音声オフ多め）、夜（PC・じっくり）。
- 求めるもの：**すぐ使えるフレーズ＋なぜそうなるかの理由**。

**ペルソナB：Emily（28歳・日本在住の英語話者）**
- 状況：日常会話はできるが、敬語や「空気」のニュアンスが分からない。
- 検索語："Japanese phrases that don't translate"、"how to say no in Japanese"
- 求めるもの：**文化の裏側＋リアルな使用例**。

> 推奨：**最初はペルソナAに一本化**。B は英語字幕／Shorts で実験的に拾い、反応が強ければ英語サブチャンネルを検討。

### 視聴者インサイト収集の手順（毎月 1 回、60 分）
1. 競合上位動画のコメント欄から「質問」「不満」「感謝」を各 20 件コピー。
2. Yahoo!知恵袋・Reddit（r/LearnJapanese, r/japanlife）・X で同テーマの悩みを 20 件収集。
3. 頻出ワードを集計し、`企画バンク`（templates/video-brief.md の下部）に追加。

## 3. 競合分析

### 手順（90分）
1. 検索窓でニッチのキーワード 10 個を検索し、上位に出るチャンネルを 10 個リストアップ。
2. 各チャンネルの「人気順」上位 10 本と「最新」10 本を確認。
3. 下表を埋める。

| チャンネル | 登録者 | 平均再生/登録者比 | 人気動画の共通型 | タイトル型 | サムネ型 | 弱点・空白 |
|-----------|--------|------------------|------------------|-----------|---------|-----------|
| 例：大手英会話系 | 100万 | 5% | ネイティブ vs 日本人 | 「〇〇は通じない」 | 顔＋大文字 | 業務場面が薄い |
| … | | | | | | |

### 見るべきシグナル
- **外れ値動画**：チャンネル平均の 3 倍以上伸びた動画 → そのテーマ／型は需要が証明済み。
- **小規模チャンネルのヒット**：登録者 1 万未満で 10 万再生以上 → 新規参入でも勝てる企画の証拠。
- **コメント欄の「〇〇もやってほしい」** → 未充足ニーズ。

### 仮ニッチでの「空白」仮説
> 大手は「ネイティブ表現の紹介」が中心。**「翻訳ツールの出力をプロが添削し、なぜダメかを日本語の構造から説明する」** 切り口はほぼ空白。
> 翻訳アプリ開発者という立場は、この切り口に圧倒的な説得力を与える。

## 4. リソース分析

| 週の時間 | 推奨ペース | 体制 |
|---------|-----------|------|
| 〜5時間 | 長尺 0.5本 + Shorts 3本 | Shorts中心、長尺は隔週 |
| 6〜10時間（仮定） | **長尺 1本 + Shorts 3〜4本** | 長尺から Shorts を切り出す |
| 11〜20時間 | 長尺 2本 + Shorts 5本 | 片方はシリーズ物で型化 |
| 20時間〜 | 長尺 2〜3本 + Shorts 毎日 | 編集外注を検討 |

**時間配分の黄金比（長尺 1 本あたり）**：企画・パッケージ 25% / 台本 20% / 撮影 15% / 編集 30% / 公開作業 10%。
→ 初心者は編集に時間を使いすぎる。**企画とパッケージに時間を寄せる**ほど再生数は伸びる。

### 顔出しの可否別フォーマット
- 顔出し可：トーキングヘッド＋画面表示（信頼が速く積み上がる、メンバーシップ向き）。
- 顔出し不可：画面録画（アプリ・翻訳画面）＋ボイスオーバー＋テロップ。仮ニッチとは非常に相性が良い。

## 5. 目標分析（逆算）

YPP 要件（**最新条件は YouTube Studio「収益化」タブで必ず確認**）：
- フル収益化（広告）：登録者 1,000 人 ＋（直近12か月の公開動画の総再生時間 4,000 時間 または 直近90日の Shorts 再生 1,000 万回）
- 拡大版（ファンファンディング等、日本対象）：登録者 500 人 ＋ 直近90日に公開動画 3 本 ＋（総再生時間 3,000 時間 または Shorts 再生 300 万回）

### 4,000 時間の逆算（長尺ルート）
- 平均視聴時間 4 分 × 必要視聴回数 = 4,000 時間 → **約 60,000 回視聴**。
- 6 か月（26 週）で達成するには週平均 約 2,300 回視聴。
- 長尺 26 本なら 1 本平均約 2,300 回、ただし実際は「外れ値 2〜3 本が全体の 50% 以上」を稼ぐのが通常。
→ 戦略的含意：**平均を上げるより、外れ値を出せる企画を毎月 1 本は打つ。** 加えて検索流入（エバーグリーン）で既存動画が毎日少しずつ時間を積み上げる構造を作る。
