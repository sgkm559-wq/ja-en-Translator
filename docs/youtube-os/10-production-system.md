# 10. 高CTR×高維持率 動画制作システム

「クリックされる理由」と「見続ける理由」を、企画の段階で設計してから撮るための手順書です。
1本ごとにこの順で進めます：**コンセプト → パッケージ（タイトル・サムネ） → フック → オープニング → 構成 → 維持の仕掛け → CTA → 台本 → 品質チェック**。

具体的な適用例は [`11-video-packages.md`](11-video-packages.md)（10本分の企画パッケージ）と [`scripts/`](scripts/)（完全台本3本）にあります。

---

## 1. 視聴者の頭の中で起きていること

視聴者は動画を見ながら、次の4つの判断を無意識に繰り返しています。各判断を通過させる設計が、このシステムの中心です。

| タイミング | 視聴者の判断 | 通過させるもの | 失敗した時の指標 |
|-----------|-------------|---------------|----------------|
| 一覧で0.5秒 | 「目に入ったか」 | サムネの視覚的コントラスト | インプレッション後の CTR 低下 |
| 一覧で2秒 | 「自分に関係あるか・知りたいか」 | タイトル＋サムネの組み合わせが作る**問い** | CTR |
| 再生後10秒 | 「期待していたものか」 | フックで約束を即回収 | 最初の30秒の維持率 |
| 再生中ずっと | 「次も見る価値があるか」 | 未解決の問い（オープンループ）を常に1つ以上持たせる | 中盤の維持率グラフの谷 |

**原則：クリックさせた問いには、動画の中で必ず答える。** 答えない釣りタイトルは、CTR が高くても維持率と満足度が落ち、おすすめに載らなくなります。

## 2. コンセプト：撮る前の4つのテスト

企画を1文で書き、4つすべてに「はい」と言えるものだけを制作します。

| テスト | 問い | 仮ニッチでの合格例 |
|-------|------|------------------|
| **ひとこと説明** | 友人に10秒で説明して「見たい」と言われるか | 「AIに『お疲れ様です』を訳させたら全部ズレてた」 |
| **当事者性** | 視聴者が「自分もやってる」と感じるか | 毎日メールで使っている言葉 |
| **意外性** | 視聴者の思い込みを1つ壊すか | 「AIの訳は丁寧なはず」→実はズレている |
| **回収できる結論** | 見終わった後に使える答えがあるか | 場面別の正しい言い方4つ |

### コンセプトを強くする5つの角度
同じテーマでも角度で伸び方が変わります。1テーマにつき5つ書き出し、最も強いものを選びます。

| 角度 | 型 | 例（テーマ：「了解しました」） |
|------|----|-----------------------------|
| 失敗 | 〇〇は実は間違い | 「Got it」は上司に使うと危ない？ |
| ランキング | 〇〇を△△順に並べる | 「了解しました」9パターン失礼な順 |
| 対決 | AとBどっちが上？ | DeepL vs ChatGPT「了解しました」対決 |
| 実験 | 〇〇してみた結果 | 1週間「Noted」だけで返信してみた |
| 謎解き | なぜ〇〇なのか | なぜ英語には「了解」がないのか |

## 3. フック（最初の5〜15秒）

### フックの6つの型

| 型 | 仕組み | 例 |
|----|-------|----|
| **① 結果見せ** | 動画の一番強い場面を先に見せる | 「AI翻訳5社に『お疲れ様です』を訳させました。……全部、ズレてました。」 |
| **② 当事者への警告** | 視聴者が今まさにしている行動を指摘する | 「メールの最初に『Thank you for your hard work』と書いている人、今すぐ止めてください。」 |
| **③ 常識の否定** | 信じていることを否定する | 「『よろしくお願いします』は英語に訳せません。どんなAIでも。」 |
| **④ 賭け・挑戦** | 結果がどうなるか分からない状態を作る | 「ネイティブ上司にAIのメールを見せて、何点つくか聞いてみます。」 |
| **⑤ 数字の約束** | 得られるものを具体的な数で示す | 「この9つを覚えれば、『了解しました』で迷うことは二度とありません。」 |
| **⑥ 問い＋即答の保留** | 問いを投げて、答えを後ろに置く | 「この英文、どこが失礼か分かりますか？答えは最後に出します。」 |

**最強の組み合わせ：「結果見せ／警告」（0〜5秒）＋「数字の約束」（5〜15秒）＋「問いの保留」（15〜30秒）。**

### フックの禁止事項
- 「こんにちは、〇〇チャンネルの△△です」から始める（挨拶は省くか、フックの後に2秒以内）
- 「今日は〇〇について話していきたいと思います」（約束が抽象的）
- タイトル・サムネと違う話題から入る（視聴者は「違った」と感じて離脱する）
- 結論を最初に全部言う（見続ける理由がなくなる）

## 4. タイトル

### 作り方
1. 動画の約束を1文で書く（例：「『お疲れ様です』の正しい英語が場面別に分かる」）
2. 下の型に当てはめて最低5案書く
3. 次の基準で絞る：**前半15文字で意味が通じる / 32文字以内 / サムネの文字と重複しない / 動画で必ず回収できる**

### タイトルの型
| 型 | 構文 | 効く心理 |
|----|------|---------|
| 警告 | 「その〇〇、実は△△です」 | 損失回避：失敗したくない |
| ランキング | 「〇〇N選【△△順】」 | 網羅欲・比較したい |
| 対決 | 「A vs B vs C：〇〇対決」 | 結果が知りたい |
| 実験・体験 | 「〇〇してみたら△△だった」 | 物語への好奇心 |
| 謎解き | 「なぜ〇〇は△△なのか」 | 理由が知りたい |
| 権威 | 「〇〇開発者が教える△△」 | 信頼・裏側を知りたい |

### サムネとタイトルの役割分担
**サムネが「感情・状況」、タイトルが「情報」。** 同じ言葉を繰り返さない。
- ✕ サムネ「お疲れ様です英語」＋タイトル「お疲れ様ですの英語」
- ○ サムネ「全滅」＋5つのAIロゴに赤×　＋　タイトル「『お疲れ様です』をAI翻訳5社に訳させたら全滅した」

## 5. サムネイル

### 設計ルール
1. **主役は1つ**（顔、または1つの英文、または比較の図）
2. **文字は8文字以内**、スマホの縮小表示で読める太さ
3. **3色まで**：このチャンネルは「白背景＋誤り＝赤×＋正解＝緑○」を固定色にする
4. **問いを作る**：見ただけでは答えが分からないこと（答えはクリックした先に）
5. 一覧で他の動画と並べて確認する（YouTube の検索結果画面のスクリーンショットに貼って比較）

### このチャンネルのサムネ型 5種
| 型 | 構図 | 使う動画 |
|----|------|---------|
| **比較×○** | 左に直訳（赤×）、右に「？？？」（答えを隠す） | テンプレ・フレーズ系 |
| **ロゴ全滅** | AIツールのロゴを並べて全部に赤× ＋ 大きく「全滅」 | AI翻訳ラボ |
| **採点表** | AIごとの点数（例：12点 / 45点 / 88点） | 対決系 |
| **驚き顔＋1行** | 顔（困惑・驚き）＋ 英文1行（赤線で消す） | 失敗・警告系 |
| **ランキング** | 「失礼 ←→ 丁寧」の矢印上に英語を並べ、1つだけ隠す | ランキング系 |

※ 他社のロゴを使う場合は、比較・批評の文脈に限り、各社のロゴ利用ガイドラインを確認してください。不安な場合はロゴではなくツール名の文字で代替します。

## 6. オープニングシーン（0〜30秒）の型

| 秒数 | 要素 | 内容 |
|-----|------|------|
| 0〜3 | **視覚フック** | タイトルの約束を映像で見せる（画面に英文、赤×の効果音） |
| 3〜8 | **言葉のフック** | 6つの型のどれか1つ |
| 8〜15 | **約束** | 「この動画を見ると〇〇できるようになる」を具体的に |
| 15〜25 | **信頼** | なぜ自分が語れるか（「翻訳アプリを作った開発者として」を1文で） |
| 25〜30 | **ループを開く** | 「最後の1つは、ネイティブでも間違えます」など最後まで見る理由 |

## 7. ストーリーテリング構成（4つの型）

教育系でも「物語」の形にすると維持率が上がります。動画のタイプで使い分けます。

### 型A：検証ストーリー（AI翻訳ラボ向け）
`問題提起 → 実験の条件 → 結果1（予想通り）→ 結果2（意外）→ 結果3（最悪）→ 原因の解説 → 正解 → 実用ルール`
- 結果は**弱い順**に出す。最も驚く結果を後半に置く。

### 型B：ランキング（テンプレ系向け）
`ランキングの基準 → 9位〜4位（テンポよく） → 中間のまとめと予告 → 3位〜1位（じっくり） → 使い分け表`
- 1位は「意外なもの」にする。視聴者の予想を外すと満足度が上がる。

### 型C：謎解き（直訳できない日本語向け）
`謎の提示 → よくある誤答 → 手がかり1（言語の仕組み）→ 手がかり2（文化）→ 答え → 応用`

### 型D：ビフォーアフター（視聴者添削・実践向け）
`ビフォーを見せる → どこが問題か当ててもらう → 1か所ずつ直す → アフター → 並べて比較 → 使える型`

### 全型共通：1項目の「4拍」
`問題（こう言いがち）→ 答え（こう言う）→ 理由（なぜか）→ 例文（実際の場面）` を30〜60秒で。

## 8. 維持テクニック 12

| # | テクニック | やり方 | 防ぐもの |
|---|-----------|-------|---------|
| 1 | **オープンループ** | 「〇〇は最後に」と予告し、必ず回収する | 中盤の離脱 |
| 2 | **リフック** | 60〜90秒ごとに「次のは一番〜」と次の価値を予告 | 緩やかな右下がり |
| 3 | **視聴者参加の間** | 「答えを出す前に3秒考えてください」→ カウントダウン | 受け身視聴による離脱 |
| 4 | **弱→強の並び** | 内容を価値の低い順に並べる | 「もう分かった」離脱 |
| 5 | **視覚の変化** | 3〜6秒ごとにカット・ズーム・テロップ・図解 | 退屈 |
| 6 | **感情の起伏** | 驚き（誤訳）→ 納得（解説）→ 安心（正解）を繰り返す | 単調さ |
| 7 | **進捗表示** | 画面隅に「3/9」などの現在地 | 「あとどれくらい？」離脱 |
| 8 | **固定の効果音** | 誤り＝ブブー、正解＝ピンポン。シリーズの記号にする | 集中切れ |
| 9 | **予想を裏切る** | 「正解だと思うでしょう？実は……」 | 予測可能さ |
| 10 | **具体的な場面** | 「金曜18時、上司が帰る時に」のように状況を描く | 抽象的で自分ごとにならない |
| 11 | **終わりの気配を消す** | 「まとめ」「最後に」を言わず、最後の項目の直後に次の動画へ | 終盤の急落 |
| 12 | **1動画1メッセージ** | 伝えたいことを1つに絞り、脱線を全カット | 崖（急落） |

## 9. CTA（行動の呼びかけ）

### 置き場所と言い方
| 場所 | タイミング | 目的 | 言い方の例 |
|------|-----------|------|-----------|
| **中盤の小さなCTA** | 価値を1〜2個届けた直後（全体の30〜60%地点） | 登録 | 「ここまでで1つでも使えると思ったら、登録してもらえると次の検証も届きます」（5秒以内） |
| **コメントCTA** | 視聴者参加の問いの直後 | エンゲージメント | 「あなたならどう訳しますか？コメントで教えてください。次の動画で添削します」 |
| **最後のCTA** | 最後の項目の直後（締めの挨拶なし） | 次の動画へ | 「でも、もっと危ないのが『よろしくお願いします』です。それはこの動画で」→ 終了画面 |
| **リードマグネット** | 中盤〜終盤（登録者300人以降） | リスト獲得 | 「今日の9パターンをまとめた表は概要欄から無料で取れます」 |

### CTAのルール
- 冒頭で「登録お願いします」と言わない（価値を届ける前の依頼は離脱を招く）
- **1回の依頼につき1つの行動**（「登録と高評価とコメントを」とまとめない）
- 最後のCTAは「次の動画を見る理由」にする。チャンネル登録より**次の1本**が成長に効く

## 10. 台本の書き方

- **話し言葉で書く**：1文は40文字以内、声に出して読んで引っかかる所を直す
- **2列で書く**：左に「話すこと」、右に「画面（テロップ・映像・効果音）」
- **英文は画面に必ず出す**、音声だけで説明しない（無音視聴が多いため）
- **1分あたり約300文字**を目安に尺を見積もる
- 書いたら声に出して読み、**全体の20%を削る**

## 11. 公開前の品質チェック（12項目）

- [ ] 企画が「4つのテスト」をすべて通っている
- [ ] タイトル5案・サムネ3案から選んだ
- [ ] サムネを検索結果画面のスクリーンショットに並べて目立つか確認した
- [ ] 最初の3秒でタイトルの約束が映像に出る
- [ ] 挨拶・自己紹介が冒頭に長く入っていない
- [ ] オープンループを開き、必ず回収している
- [ ] 60〜90秒ごとにリフックがある
- [ ] 英文はすべて画面に表示され、内容を英語話者または信頼できる資料で確認した
- [ ] AIツールの出力は**実際にその日に取得した結果**を使い、取得日を画面に表示した
- [ ] 中盤のCTAは5秒以内
- [ ] 最後は締めの挨拶なしで次の動画へつないでいる
- [ ] 維持率グラフを見る日（公開48時間後）をカレンダーに入れた

## 12. 公開後の振り返り（48時間後・7日後）

| 指標 | 見る場所 | 低い時に直す場所 |
|------|---------|----------------|
| CTR | リーチ | サムネ → タイトルの順に差し替え（「テストと比較」機能） |
| 30秒維持率 | 維持率グラフ | オープニング（フックと約束のズレ） |
| 中盤の谷 | 維持率グラフ | その直前にリフックを入れる型を次回から追加 |
| 平均視聴率 | エンゲージメント | 構成の並び順、項目数 |
| 登録者増／再生100回 | 視聴者 | 中盤CTAの位置、チャンネルの約束の明確さ |
| 終了画面のクリック率 | エンゲージメント | 最後のCTAで次の動画への「理由」を言っているか |

学んだことは本ファイルの該当セクションに1行で追記し、次の動画からルールとして使います。
