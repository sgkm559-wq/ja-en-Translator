# 04. 視聴維持フレームワーク

目標値（教育系・長尺 8〜12 分の目安）：
- **最初の 30 秒維持率 ≥ 70%**
- **平均視聴率 ≥ 40%**（12分以上の動画は ≥ 35%）
- Shorts：**視聴率（Viewed vs Swiped away）≥ 70%**、平均視聴率 ≥ 80%

## 1. 台本構造「H.O.O.K. → L.O.O.P.」

| 区間 | 時間 | 中身 | 目的 |
|------|------|------|------|
| **Hook** | 0〜5秒 | タイトル・サムネの約束を即座に映像で回収（例：AI の誤訳を画面に出して「これ、上司に送ったら終わります」） | クリック後の「違った」感の排除 |
| **Outcome** | 5〜15秒 | この動画で得られるものを具体的に（「7 パターン覚えれば、どの場面でも失礼にならない」） | 見続ける理由 |
| **Open loop** | 15〜30秒 | 最後まで見る理由を仕込む（「最後の 1 つは、ネイティブでも間違えます」） | 終盤までの牽引 |
| **Kick-off** | 30秒 | 前置きなしで本題へ（自己紹介は 3 秒以内か省略） | 序盤離脱の防止 |
| **Layers** | 本編 | 1 項目 = 「問題 → 答え → 理由 → 例文」の 4 拍。項目は弱→強の順に並べる | テンポと期待の上昇 |
| **Re-hooks** | 60〜90秒ごと | 「次のは一番よく使うのに一番間違える」など、次の価値を予告 | 中盤の谷を防ぐ |
| **Payoff** | 終盤 | Open loop の回収（最も価値のある内容をここに） | 満足度・高評価 |
| **Pass** | 最後10秒 | 「この動画で〇〇が分かったなら、次は△△で□□を」→ 終了画面へ直結。締めの挨拶は省く | セッション継続 |

## 2. 編集ルール（パターン・インタラプト）
- **3〜6 秒ごとに視覚変化**（カット、ズーム、テロップ、画面切替、図解）
- 英文は **必ず画面に大きく**、日本語訳を下段に。重要語はハイライト
- 「えー」「あの」「間」はすべてカット。ジャンプカットを恐れない
- BGM は小さく、話の区切りでだけ変化
- 柱①では誤訳に「×」SE、正解に「○」SE を固定（シリーズの記号化）

## 3. Shorts の維持ルール
- 1 フレーム目から本題（「これ、英語で言えますか？」を文字で）
- 字幕は画面中央上寄り（UI に隠れない位置）
- 最後を最初につなげて **ループ** させる（例：最後の一言が冒頭の問いに戻る）
- 長尺への導線：「関連動画」設定で該当長尺をリンク

## 4. 維持率グラフ診断表

公開 48 時間後、YouTube Studio「視聴者維持率」を見て下表で原因を特定する。

| グラフの形 | 原因 | 打ち手 |
|-----------|------|-------|
| 冒頭 30 秒で急落 | パッケージと中身のズレ／前置きが長い | Hook で約束を即回収。挨拶削除 |
| 緩やかに右下がり | テンポ不足 | 視覚変化を増やす、項目を短く |
| 特定箇所で崖 | 退屈・脱線・解決済み感 | その区間を削除 or 前に Re-hook を追加 |
| 山（上昇） | 巻き戻し＝価値が高い／分かりにくい | 価値なら Shorts 化・次回企画の種に |
| 終盤で急落 | 「終わりの気配」 | まとめを短縮、Payoff を最後に置く |

## 5. 維持率改善の 1 週 1 改善ループ
1. 最新動画の「最大の崖」を 1 つ特定
2. 原因仮説を 1 行で書く
3. 次の動画で 1 つだけ変える
4. 翌週比較 → 効果があればルール化して本ファイルに追記
