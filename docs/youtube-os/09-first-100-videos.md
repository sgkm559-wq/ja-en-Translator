# 09. 最初の100本：成長ポテンシャル順ランキング

## 採点方法

**成長スコア（100点満点）＝ 需要 30 ＋ クリックの強さ（おすすめ適性）25 ＋ 検索ポテンシャル 20 ＋ 差別化 15 ＋ 制作しやすさ 10**

- カテゴリ：A＝AI翻訳ラボ / B＝仕事の英語テンプレ / C＝直訳できない日本語 / D＝AI×英語学習ハック / E＝実践・視聴者参加
- 形式：L＝長尺（8〜15分）/ S＝Shorts
- 流入：検＝検索 / お＝おすすめ・関連 / 両＝両方 / 登＝既存の登録者・通知
- スコアは定性評価です。公開後は実データ（CTR・維持率・登録者増）で順位を入れ替えてください。

> **注意：ランキング順＝公開順ではありません。** 新規チャンネルはおすすめのデータが少ないため、
> 末尾の「推奨公開順」のとおり、**検索で見つかる動画 → おすすめ狙いの動画** の順に混ぜて出します。
