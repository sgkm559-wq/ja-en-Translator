# YouTube 収益化オペレーティングシステム（YT-OS）

ゼロから YouTube パートナープログラム（YPP）参加要件を達成するための、
「分析 → 設計 → 実行 → 計測 → 改善」を毎週回す運用システムです。

> **前提について（必ずお読みください）**
> ニッチ・視聴者・競合・リソース・目標の具体的な情報がまだ共有されていないため、
> 本システムは **(1) どのニッチにも使えるフレームワーク** と
> **(2) このリポジトリ（日英翻訳アプリ）から推定した仮ニッチ「日本語⇄英語の“使える”言語・文化」での具体例**
> の二層構造で作っています。`00-intake.md` を埋めていただければ、具体例部分をあなたの実情に差し替えて精緻化できます。

## 使い方（最短ルート）

1. **Day 0（60分）**：`00-intake.md` を埋める。
2. **Day 1（90分）**：`01-analysis.md` の手順で競合 10 チャンネルを調査し、「勝ち筋の空白」を 1 文で書く。
3. **Day 2（60分）**：`02` でポジショニング文と 3 本柱を確定。
4. **Day 3〜**：`07-weekly-execution.md` の週次サイクルを開始。最初の 30 日は「量と型の確立」、
   31〜60 日は「勝ちフォーマットの特定」、61〜90 日は「勝ちフォーマットの量産とシリーズ化」。
5. **毎週日曜（45分）**：`templates/kpi-tracker.csv` を更新し、`07` のレビュー質問に答えて翌週の実験を 1 つ決める。

## システムの中心原則

1. **パッケージ（タイトル×サムネ）が先、動画は後。** クリックされない動画は存在しないのと同じ。企画段階でタイトルとサムネ案を 3 つ作り、勝てない企画は撮らない。
2. **視聴者は「チャンネル」ではなく「次の1本」を選ぶ。** 1 本ごとに「誰の・どんな問題を・どう変えるか」を明確に。
3. **一貫性 > 頻度 > 完成度。** 毎週同じ曜日・同じ型で出すことが、アルゴリズムにも視聴者にも最大のシグナル。
4. **1週1実験。** 変数を 1 つだけ変え、データで判断する。
5. **長尺で信頼を、Shorts で発見を。** 収益化の時間要件は長尺が稼ぎ、Shorts は入口を広げる。
