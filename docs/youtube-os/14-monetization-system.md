# 14. 収益化システム（完全版）

[`06-monetization-plan.md`](06-monetization-plan.md) の概要を、**収益源ごとの具体的な手順と、成長段階ごとの導入タイミング** まで落とし込んだものです。

> **前提と注意**
> - YouTube の条件・分配率、各サービスの手数料、日本の税制・法律は変わります。数値は2026年10月時点の一般的な情報で、**導入前に必ず公式情報で確認**してください。

> - 金額のシミュレーションは仮定にもとづく目安で、実績ではありません。

## 1. 全体設計：収益の「はしご」

収益化の考え方は、**広告に頼らず、視聴者が段階的に深く関わる仕組みを作ること**です。広告収益は登録者が少ないうちは小さく、アルゴリズムや景気にも左右されます。

### 価値のはしご（このチャンネルの場合）

| 段 | 内容 | 価格の目安 | 視聴者の関わり方 |
|---|------|-----------|----------------|
| 0 | YouTube 動画・Shorts | 無料 | 見る |
| 1 | 無料の早見表・チェックリスト（リードマグネット） | 無料（メール/LINE登録） | 連絡先を預ける |
| 2 | ニュースレター・LINE 配信 | 無料 | 毎週受け取る |
| 3 | アフィリエイト（学習サービス・ツール） | 紹介料 | 推薦を信頼して使う |
| 4 | テンプレ集・フレーズ集（デジタル商品） | 980〜4,980円 | 初めて買う |
| 5 | メンバーシップ | 月490〜1,490円 | 継続的に支援・参加する |
| 6 | オンライン講座 | 1.5万〜5万円 | 本気で学ぶ |
| 7 | 個別添削・法人研修 | 3万円〜／回 | 直接サービスを受ける |
| 他 | 自作翻訳アプリの有料プラン | 月額・買い切り | 道具として毎日使う |

**原則：下の段で信頼を作ってから、上の段を売る。** いきなり講座を売るのではなく、無料の早見表 → 有料テンプレ → 講座 の順に、視聴者が「この人の教え方は役に立つ」と確認できる流れを作ります。

### 収益の流れ（ファネル）
```
YouTube（長尺・Shorts）
   │ 概要欄・固定コメント・動画内の案内
   ▼
無料の早見表（リードマグネット） ──→ メール / LINE リスト
   │                                   │ 週1配信で信頼を積む
   ▼                                   ▼
アフィリエイト・テンプレ集 ───────→ 講座・メンバーシップ・添削
                                       │
                                       ▼
                                  法人研修・アプリ有料プラン
```

## 2. 成長段階と導入タイミング（全体像）

| 段階 | 登録者の目安 | 主な目標 | 導入する収益源 |
|-----|------------|---------|--------------|
| **0. 準備期** | 0〜100 | 型を作る | 収益化の土台づくり（アカウント・税務・リンク管理）、自作アプリへの導線 |
| **1. 信頼形成期** | 100〜500 | 見つけてもらう、信頼を作る | アフィリエイト、リードマグネット＋メール/LINE |
| **2. 初期収益期** | 500〜1,000 | 拡大版 YPP | 最初のデジタル商品、メンバーシップ、Super Thanks |
| **3. 収益化達成期** | 1,000〜1万 | フル YPP | 広告収益、商品の追加、講座の先行販売、小規模スポンサー |
| **4. 事業化期** | 1万〜5万 | 収益源の多角化 | 講座の本格販売、スポンサー、法人研修、有料コミュニティ |
| **5. 拡大期** | 5万〜 | 仕組み化・チーム化 | 書籍、英語サブチャンネル、ライセンス、外注・チーム化 |

**登録者数はあくまで目安です。** 実際の判断は「その収益源の前提条件を満たしているか」（各章に記載）で行います。例えば登録者300人でも、コメントで「テンプレがほしい」という声が多ければ、商品を先に出す価値があります。

## 3. YouTube パートナープログラム（YPP）の準備

### 条件（YouTube Studio「収益化」タブで最新を確認）
| 段階 | 条件 | 使える機能 |
|-----|------|----------|
| 拡大版 YPP | 登録者500人 ＋ 直近90日に公開動画3本 ＋（直近12か月の公開長尺の総再生時間3,000時間 または 直近90日の Shorts 視聴回数300万回） | メンバーシップ、Super Thanks / Super Chat / Super Stickers、ショッピング |
| フル YPP | 登録者1,000人 ＋（直近12か月の公開長尺の総再生時間4,000時間 または 直近90日の Shorts 視聴回数1,000万回） | 上記＋**広告収益**、YouTube Premium の収益分配 |

### 審査に通るための準備チェックリスト
- [ ] Google アカウントの2段階認証
- [ ] コミュニティガイドラインの違反警告（ストライク）がない
- [ ] YouTube チャンネルの収益化ポリシーを読んだ
- [ ] **独自性**：全動画に自分の解説・検証・意見が入っている（AI音声で他人の情報を読むだけ、同じ型の大量生産は審査で不利）
- [ ] 他人の動画・映像の転載がない。他社ツールの画面は検証・批評の範囲
- [ ] BGM・効果音・画像はすべて商用利用可
- [ ] チャンネル概要欄・バナーでチャンネルの目的が分かる
- [ ] 審査で見られやすい「最新の動画」「再生回数の多い動画」「総再生時間の多い動画」の品質を見直した
- [ ] AdSense アカウントを準備（次章）

### 審査に落ちた場合
- 落ちた理由（「再利用されたコンテンツ」など）が通知されます。
- 原則として **30日後に再申請** できます。指摘された点に該当する動画を修正・非公開にし、独自の解説を増やしてから再申請します。

## 4. AdSense・広告収益戦略

### 基本の仕組み
- 長尺動画の広告収益：**クリエイターの取り分は55%**（YouTube が45%）
- Shorts の広告収益：Shorts 全体の広告収益をクリエイター向けプールに入れ、視聴回数のシェアに応じて分配し、**その45%がクリエイター**の取り分
- **RPM**（1,000回視聴あたりの実際の収益）で考えます。CPM（広告主が払う額）ではありません。

### 準備
- [ ] AdSense アカウントを本人名義・正しい住所で作成（YouTube Studio の収益化の手順から連携）
- [ ] 住所確認の PIN（郵送）を入力
- [ ] 支払い方法（銀行口座）を登録。日本の支払い基準額（一定額以上たまると翌月支払い）を確認
- [ ] **米国の税務情報（W-8BEN）を提出**：米国の視聴者から得た収益には源泉徴収がかかります。日本在住者は日米租税条約の適用を申告すると税率を下げられます（提出しないと高い税率で差し引かれる可能性）。手順は AdSense の「お支払い → 税務情報」で確認

### RPM を上げる方法
| 施策 | やり方 | 注意 |
|-----|-------|------|
| **8分以上の動画** | ミッドロール（途中の広告）を入れられる | 中身を水増ししない。維持率が下がると逆効果 |
| **ミッドロールの位置** | 自動配置ではなく、話の区切り（項目と項目の間）に手動で2〜3か所 | 盛り上がりの直前や説明の途中には入れない |
| **広告単価の高いテーマ** | 転職・キャリア、ビジネス、ツール比較、学習サービスは広告主が多い | テーマは視聴者の関心が最優先。単価だけで選ばない |
| **季節性を意識** | 10〜12月は広告単価が上がりやすく、1月は下がりやすい | 10〜12月にエバーグリーンの力作を出す |
| **検索型の動画を増やす** | 長期間、毎日少しずつ再生される動画は広告収益の土台になる | |

### 広告収益の位置づけ
登録者1,000〜1万人の段階では、広告収益は**全体の一部**と考えます。広告収益が増えるのを待たず、アフィリエイトや商品を並行して育てます。

## 5. アフィリエイトマーケティング

### 導入タイミング
**段階1（登録者100人〜）から。** YPP の条件を満たす前から始められる、最初の収益源です。

### 前提条件
- 紹介する商品・サービスを**自分で実際に使い、良いと判断している**
- 動画の内容と自然につながる

### 紹介するものの候補（このチャンネルの場合）
| 分類 | 例 | 相性の良い動画 |
|-----|----|-------------|
| オンライン英会話・英語学習サービス | 体験レッスン登録で紹介料が出るもの | 「AIで英語メールを書く→次は話す練習」 |
| 英語学習アプリ・英文チェックツール | 文法チェック、AI 英作文ツール | ツール比較・ワークフロー紹介 |
| AI ツールの有料プラン | 翻訳・文章作成ツール | AI翻訳ラボ |
| 転職エージェント・転職サービス | 英語を使う仕事の求人 | 英語面接・英文レジュメ |
| 書籍・辞書 | ビジネス英語の本、コロケーション辞典 | 深掘り解説 |
| 機材 | マイク、Webカメラ（オンライン会議用） | 「英語会議を聞き取りやすくする」系 |

### アフィリエイトの登録先（日本で代表的なもの）
- Amazon アソシエイト（書籍・機材）
- A8.net、もしもアフィリエイト、バリューコマース など（英会話・転職・サービス系の案件が多い）
- 各サービスの公式紹介プログラム
- YouTube ショッピングのアフィリエイト（日本での提供状況・条件は YouTube Studio で確認）

### 置き場所
| 場所 | やり方 |
|-----|-------|
| 動画の中 | 「この検証で使った〇〇」と、使う場面を見せる。宣伝はその1回だけ |
| 説明欄 | 上から3行以内に、動画に関係するものを1〜2個だけ |
| 固定コメント | 動画のテーマに直結するものだけ |
| リンク集ページ | 「おすすめの学習ツール」ページを作り、全動画から案内 |
| ニュースレター | 「今月実際に使ったツール」として紹介 |

### 必須：広告であることの表示
- **ステルスマーケティング規制（景品表示法）**：2023年10月から、広告であるのに広告と分からない表示は違法です。アフィリエイトリンクを含む動画・説明欄・SNS投稿には **「PR」「広告」「アフィリエイトリンクを含みます」** などを分かりやすく表示します。
- **YouTube の設定**：企業から金銭等を受けている場合は、アップロード時に「有料プロモーション」にチェックを入れます（アフィリエイトのみの場合も、YouTube のポリシーと各案件の規約を確認）。

### 指標
- 説明欄リンクのクリック率（リンク短縮・計測ツールで動画別に計測）
- 成約率、1,000回視聴あたりのアフィリエイト収益
- **成約後の解約・返品**（紹介したものが本当に役立っているか）

## 6. リードマグネットとニュースレター（メール / LINE）

### 導入タイミング
**段階1（登録者100〜300人〜）。** アフィリエイトと同時に始めるのが理想です。

### なぜ早く始めるのか
YouTube の視聴者は「アルゴリズムを通してしか届かない相手」です。メールや LINE のリストは**自分で直接届けられる資産**で、商品・講座を出す時の売上の大部分はここから生まれます。

### リードマグネット（無料の特典）
| 候補 | 内容 | 相性の良い動画 |
|-----|------|-------------|
| **英語メール書き出し・結びの早見表** | 場面別の定型文を1枚に | 「お疲れ様です」「よろしくお願いします」 |
| **AI英語チェックリスト** | 送信前に確認する5項目 | 「そのAI英語、そのまま送るな」 |
| **ChatGPT 英文プロンプト集** | コピペで使えるプロンプト10個 | AI×英語学習ハック |
| **「了解しました」使い分け表** | 9パターンの表 | ランキング系 |

### 配信ツールの選び方
| ツール | 向いている使い方 |
|-------|---------------|
| **LINE 公式アカウント** | 日本の視聴者に届きやすい。短い案内と通知向き。メッセージ数に応じた料金体系なので配信数に注意 |
| メール配信サービス（Kit、Beehiiv、Benchmark など） | 長めの記事、商品販売の自動化（ステップメール） |
| note のメンバーシップ・マガジン | 文章で発信し、有料化もしやすい |

最初は **LINE 公式アカウント1つ** で始め、リストが500人を超え、商品販売を自動化したくなったらメール配信を追加するのが手間の少ない方法です。

### 配信内容（週1回）
- 今週の動画の要点（1つ）
- 動画で言えなかった補足・裏話
- 視聴者からの質問への回答
- 月に1〜2回だけ、アフィリエイトや自分の商品の案内（**価値提供：案内 ＝ 4：1** 程度）

### 法律上の注意
- 広告・宣伝を含むメールを送る場合は、**特定電子メール法**により、事前の同意取得、送信者情報の表示、配信停止の方法の明示が必要です。
- 個人情報の取り扱い方針（プライバシーポリシー）を用意します。

### 指標
- 1,000回視聴あたりのリスト登録数、配信の開封率・クリック率、配信停止率

## 7. デジタル製品

### 導入タイミング
**段階2（登録者500人〜）。** 前提条件を満たせば、もっと早くても構いません。

### 前提条件
- リスト（メール / LINE）が100人以上
- コメントや質問で「〇〇がほしい」「〇〇がまとまっていれば」という声が繰り返し出ている
- 無料のリードマグネットが実際にダウンロードされている

### 商品候補
| 商品 | 内容 | 価格の目安 |
|-----|------|-----------|
| **ビジネス英語メール完全テンプレ集** | 依頼・催促・謝罪・お礼など50場面、日英対訳＋使い分けの注意 | 1,980〜3,980円 |
| **AI英語ワークフロー・プロンプト集** | 場面別プロンプト30個＋チェックリスト | 980〜2,480円 |
| **Slack・チャット英語フレーズ集** | 社内チャットの定型文と温度感の調整方法 | 980〜1,980円 |
| **Notion 英語学習テンプレート** | 自分のフレーズ帳・AI添削ログ | 980〜1,980円 |
| 上記のセット | まとめ買い割引 | 4,980〜6,980円 |

### 作り方（最小限の検証から）
1. **まず無料版を出す**：リードマグネットとして一部を配布し、反応を見る
2. **先行予約・事前販売**：完成前に「〇月〇日に公開、先行価格」と告知し、購入が一定数あれば完成させる（ない場合は返金して中止）
3. **販売開始**：リストに先行案内 → 動画で紹介
4. **改善**：購入者の質問を集めて改訂版を出す（購入者には無料アップデート）

### 販売プラットフォーム
- note、BOOTH、STORES、BASE、Stripe の決済リンクなど。手数料・入金サイクル・ダウンロード配布の機能で選ぶ

### 必須の表示
- **特定商取引法に基づく表記**（販売者名、連絡先、価格、支払方法、引き渡し時期、返品・キャンセルの扱いなど）。個人の場合、住所・電話番号を請求があった場合に開示する方法をとれるプラットフォームもあります。

## 8. メンバーシップ

### 導入タイミング
**段階2（拡大版 YPP 達成後）。** YouTube のチャンネルメンバーシップは YPP 参加が条件です。

### 前提条件
- 毎回コメントしてくれる常連が30人以上いる
- **毎月、継続して提供できる特典**がある（特典が続かないと解約が増える）

### 特典の設計（無理なく続けられるもの）
| ランク | 月額の目安 | 特典 |
|-------|----------|------|
| サポーター | 120〜290円 | 名前の入ったバッジ・絵文字、コメント欄での優先返信 |
| 学習メンバー | 490〜990円 | 月1回の限定動画（「今月のAI誤訳まとめ」）、限定のフレーズ PDF |
| 添削メンバー | 1,490〜2,990円 | 月1回、英文を1通添削（ライブまたは動画で）、限定ライブへの参加 |

### 運営のコツ
- 特典は**作るのに時間がかからないもの**にする（ライブ、既存動画の深掘り、PDF）
- 毎月同じ日に限定コンテンツを出す
- YouTube の手数料（メンバーシップ収益の一部）を差し引いた手取りで計算する

### 代替・併用
- 長文の発信が得意なら note のメンバーシップ、交流の場を作るなら Discord（YouTube メンバーシップと連携できる機能あり）

## 9. Super Thanks・Super Chat・ライブ

### 導入タイミング
**段階2（拡大版 YPP 達成後）。**

- **Super Thanks**：通常の動画で視聴者が感謝の気持ちを送れる機能。設定をオンにするだけで、手間はほとんどかからない
- **Super Chat**：ライブ配信中のメッセージ。月1回の「英文添削ライブ」と相性が良い
- ライブでは、Super Chat で送られた英文を優先的に添削する、などの理由づけをすると使われやすい

## 10. スポンサーシップ（企業案件）

### 導入タイミング
**段階3（登録者1,000〜5,000人）から小規模に、段階4で本格化。** 登録者が少なくても、視聴者が明確なチャンネルは声がかかることがあります。

### 前提条件
- 視聴者層（年齢・性別・地域・関心）を説明できる
- 平均視聴回数が安定している（直近10本の平均）
- 紹介したい企業の商品・サービスを自分が本当に勧められる

### メディアキット（1〜2ページ）に入れるもの
- チャンネルの約束と視聴者像（YouTube Studio の視聴者データ）
- 登録者数、直近30日・90日の視聴回数、**直近10本の平均視聴回数**
- 平均視聴時間、主な視聴者層、主な流入元
- 過去の実績（アフィリエイトの成約実績、コメントの反応）
- 提供できるメニューと料金（後述）
- 連絡先

### メニューと料金の考え方
| メニュー | 内容 | 料金の考え方 |
|---------|------|------------|
| 動画内の紹介（60〜90秒） | 本編の中で商品を紹介 | 平均視聴回数をもとに「1再生あたり〇円 × 想定視聴回数」で計算するのが一般的 |
| 専用動画（タイアップ） | 1本まるごと商品を検証 | 動画内紹介の2〜3倍程度＋制作費 |
| Shorts | 縦型動画での紹介 | 動画内紹介より安く設定 |
| 説明欄・固定コメント | リンクの掲載 | オプション |
| 二次利用 | 企業の広告として動画を使う | 期間・媒体に応じて追加料金 |

※1再生あたりの単価は、ジャンル・視聴者層・エンゲージメントで大きく異なります。最初は相場を調べ、受けた案件の成果（クリック数・成約数）を記録して、次の交渉の材料にします。

### 自分から営業する方法
1. 動画でアフィリエイト紹介して**実際に成果が出たサービス**をリストアップ
2. 成果のデータ（クリック数・成約数）を添えて、そのサービスの広報・マーケティング担当に連絡
3. インフルエンサーマーケティングのマッチングサービスへの登録も検討

### 契約時のチェックリスト
- [ ] 内容の自由度：**自分の正直な意見（良くない点を含む）を言ってよいか**
- [ ] 台本・動画の確認回数と修正の範囲
- [ ] 公開日、公開期間（削除してよい時期）
- [ ] 二次利用の範囲と期間
- [ ] 競合他社の案件を受けられない期間（排他条件）
- [ ] 支払い条件（金額、支払日、請求書の形式）
- [ ] **インボイス**：企業から適格請求書（インボイス）の発行を求められることがある。登録するかどうかは売上規模を踏まえて税理士に相談

### 必須の表示
- YouTube のアップロード時に「有料プロモーション」をオン
- 動画の冒頭・説明欄にも「PR」「提供：〇〇」と分かりやすく表示（ステルスマーケティング規制）

### 断る基準
- 自分が使って良いと思えない、視聴者の役に立たない、チャンネルの約束とずれる案件は断る。**視聴者の信頼が、すべての収益源の土台**です。

## 11. オンライン講座

### 導入タイミング
**段階3で先行販売（小規模に検証）、段階4で本格販売。**

### 前提条件
- デジタル商品が売れた実績があり、購入者から「もっと詳しく」「実践したい」という声がある
- リストが500人以上

### 講座の設計例
**「4週間で、AIを使って失礼にならない英語メールが書けるようになる講座」**

| 週 | 内容 | 課題 |
|---|------|------|
| 1 | 英語メールの型（書き出し・本題・結び）とAIへの指示の出し方 | 自分の仕事のメールを1通、AIと一緒に書く |
| 2 | 依頼・催促・断りの温度感の調整 | 3場面のメールを書く |
| 3 | 謝罪・クレーム対応・交渉 | 難しい場面のメールを書く |
| 4 | 自分専用テンプレの完成とチェックの習慣化 | 自分のテンプレ集を作る |

### 形式の選び方
| 形式 | 特徴 | 価格の目安 |
|-----|------|-----------|
| 録画講座（自分のペースで学ぶ） | 一度作れば繰り返し売れる。完走率は低め | 9,800〜29,800円 |
| 少人数のグループ講座（期間を決めて一緒に進む） | 添削・質問対応あり。完走率と満足度が高い。最初の検証に最適 | 29,800〜59,800円 |
| 個別添削付き | 手厚いが、時間あたりの収益に上限がある | 50,000円〜 |

### 進め方
1. **最初はグループ講座を少人数（5〜15人）で先行販売**：受講生の反応を見ながら内容を作り込む
2. 受講生の感想・成果（掲載の許可を取る）を集める
3. 内容が固まったら録画講座にして、常時販売する
4. 年に2〜4回、グループ講座を募集する

### プラットフォーム
- 自分のサイト＋決済サービス、講座販売プラットフォーム、Udemy（集客力はあるが価格の自由度は低い）など。手数料、受講生のデータを自分で持てるか、で選ぶ

### 注意
- 講座内容の効果を誇大に表示しない（「必ず話せるようになる」などの断定は避ける）
- 返金の条件を事前に明示する

## 16. 収益の指標（月次でチェック）

| 指標 | 計算 | 見るポイント |
|-----|------|------------|
| **RPM（総合）** | 全収益 ÷ 視聴回数 × 1,000 | 広告だけでなく、全収益で計算する |
| リスト登録率 | 新規リスト登録 ÷ 視聴回数 × 1,000 | リードマグネットと案内の強さ |
| 収益源ごとの割合 | 各収益 ÷ 全収益 | 1つの収益源が50%を超えたら、依存のリスク |
| 購入者の再購入率 | 2回以上買った人 ÷ 購入者 | 信頼の深さ |
| メンバーシップの継続率 | 前月から継続したメンバー ÷ 前月のメンバー | 特典の価値 |
| 1時間あたりの収益 | 収益源ごとの収益 ÷ かけた時間 | 時間をかける価値がある収益源か |

## 18. 収益化で信頼を失わないためのルール

1. **自分が使っていないものは勧めない**
2. **広告・PR は必ず明示する**
3. **動画の価値を、収益化のために削らない**（宣伝は1本につき1か所、短く）
4. **無料で最も価値のあるものを出し続ける**（有料商品は「まとめ・実践・サポート」に価値を置く）
5. **購入者を一番大切にする**（質問への回答、無料アップデート）

視聴者の信頼は、すべての収益源の土台です。短期の収益のために信頼を失うと、すべての収益源が同時に弱くなります。
